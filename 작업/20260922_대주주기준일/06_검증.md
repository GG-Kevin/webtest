### V-31 · 원고 `<!-- 4-3 -->` — **지분율도 같은 문제. 「넘어도」가 아니라 「이상」이다**

원고: 「코스피 1퍼센트, 코스닥 2퍼센트, 코넥스 4퍼센트이고 **둘 중 하나만 넘어도** 대주주입니다」

**퍼센트 값 셋과 「이거나(OR)」 구조는 맞다. 틀린 것은 「넘어도」 하나다.** 지분율 정확히 1%·2%·4%면 해당한다. **「둘 중 하나만 닿아도」 또는 「하나라도 그 선 이상이면」으로 고친다.**

```

grep -o -F '100분의 2' L1_…본문.txt | wc -l → 1   (제2항제1호 코스닥)
grep -o -F '100분의 4' L1_…본문.txt | wc -l → 1   (제2항제2호 코넥스)
```

## 4. 「진행」이 먼저 센 값과의 차이 — 왜 다른가

「진행」: 고유 **25종 · 총 65회**. 「검증」: 검사 항목 **50건**.

**같은 것을 세지 않았다.** 「진행」의 정규식은 **문자열의 종류와 출현 횟수**를 센다. 「검증」이 센 것은 **대조해야 할 사실 단위**다. 예를 들어
- 「12월 30일」 7회는 「진행」에게 1종·7회지만, 「검증」에게는 **V-6(마지막 거래일)·V-9(종가 기준일) 두 항목**이다. 근거가 다른 조문·다른 파일이기 때문이다.
- 반대로 「12월 25일」 2회와 「12월 31일」 6회는 「검증」에게 **V-4·V-5 두 항목**으로 줄어든다. 둘 다 `K1` 한 줄씩으로 끝난다.
- 「진행」의 정규식이 아예 못 잡은 것이 **인용 6건의 축자 일치(V-12·18·25·30·35·41)**와 **경위 서술 4건(V-10·36·43·47)**, **내부링크 3건(V-49a~c)**이다. 이 13건은 숫자가 아니라서 정규식에 안 걸린다.

**「검증」이 센 방법**
```
# 본문만 잘라낸 뒤 수치·법령·날짜·인용·고유명사를 전부 뽑고, 근거 파일이 갈리는 지점에서 항목을 나눴다
awk '/^## 본문/{f=1;next} /^## 집필 메모/{f=0} f' 05_원고.md \
 | grep -oE "[0-9]+월 [0-9]+일|[0-9]{4}년|[0-9]+억|[0-9]+퍼센트|제[0-9]+조|제[0-9]+항|제[0-9]+조의[0-9]+|소득세법[^ ]*|국세기본법[^ ]*|시행령|오후 [0-9]+시|250만원" \
 | sort | uniq -c | sort -rn
```
**「진행」의 값이 틀렸다는 뜻이 아니다. 세는 단위가 다르다.**
