## 2. A와 B는 **한 벌에서 나왔다** (결정 71)

`build.py` 한 번이 본문 조각(`FRAG`)을 만들고, **그 똑같은 조각을 B에 그대로 쓰고 A의 `<h1>` 아래에 그대로 끼운다.** 손으로 두 번 쓴 곳이 없다.

```
BODY_BLOCK = '<!-- BODY-START -->' + FRAG + '<!-- BODY-END -->'
B = BODY_BLOCK                       # 업로드용 TXT = 이것 전부
A = <head><style>…</style></head><body> … <h1>제목</h1> + BODY_BLOCK + </body>
```

**`<!-- BODY-START -->` / `<!-- BODY-END -->`는 화면에 안 보이는 주석이고, A·B 어디서든 본문 구간을 기계로 잘라낼 수 있게 두었다.** 나중에 누가 다시 대조할 때 쓰라고 남긴 것이다.
