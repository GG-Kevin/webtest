## 2. A와 B는 **한 벌에서 나왔다** (결정 71)

`build.py` 한 번이 본문 조각(`FRAG`)을 만들고, **그 똑같은 조각을 B에 그대로 쓰고 A의 `<h1>` 아래에 그대로 끼운다.** 손으로 두 번 쓴 곳이 없다.

```
BODY_BLOCK = '<!-- BODY-START -->' + FRAG + '<!-- BODY-END -->'
B = BODY_BLOCK                       # 업로드용 TXT = 이것 전부
A = <head><style>…</style></head><body> … <h1>제목</h1> + BODY_BLOCK + </body>
```

**`<!-- BODY-START -->` / `<!-- BODY-END -->`는 화면에 안 보이는 주석이고, A·B 어디서든 본문 구간을 기계로 잘라낼 수 있게 두었다.** 나중에 누가 다시 대조할 때 쓰라고 남긴 것이다.

**md5 3개 일치** — `d2d439a0fb137400bf4d579658f958ac` · len 4976. 센 명령어와 정규화 규칙은 `06_화면검사.md` 4절.

## 4. 본문에 없는 것을 약속하지 않았다

**제목이 단정한 두 값이 본문 표1에 실물로 있다.**

| 제목이 말한 것 | 본문 어디 |
|---|---|
| 「대주주 기준일은 12월 31일」 | 표1 **「대주주 판정 기준일」** 칸 + 문단 `1-4` |
| 「50억은 12월 30일 종가」 | 표1 **「50억을 재는 값」** 칸 + 문단 `1-5` |

**A의 `<h1>`은 `06_제목.md` 1순위 문자열 그대로다.** 한 글자도 안 고쳤다(「포착」 영역).

```
python3 -c "print(len('2026년 대주주 기준일은 12월 31일이지만 50억은 12월 30일 종가입니다'))" → 44
diff <(sed -n '30p' 06_제목.md | sed 's/^> ### \*\*//; s/\*\*$//') 06_발행_제목.txt  → 차이 0
```

**「비어 있다」고 적은 칸을 이미지나 서식으로 덮지 않았다.** 표1 「마지막 매도 체결일 = 1차 미확인」은 화면에도 그대로 「1차 미확인」으로 선다.
