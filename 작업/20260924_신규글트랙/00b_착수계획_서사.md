# 00b 착수계획 — 「서사」 몫 (잠정)

**재료(청취·수집·해부·설계서) 전이다. 아래 전부 「잠정」이다.** 설계서가 구조를 지정하면 그쪽이 앞선다.
근거로 연 것: `02_탐침.md` §1·§5·§6 · `02b_도달상한.md` · `운영/작법표본/01_작법기준.md` §0·§6·§7·§12·§13.

## 1. 분량 — 잠정

| 항목 | 값 |
|---|---|
| 본문 목표 | **3,000~3,800자** (공백 포함, 마크업 제외) |
| **상한** | **4,000자.** 넘기려면 사장에게 다시 묻는다 |
| 근거 | 상위 24편 길이 중앙값 2,812자, 4,000자면 이미 상위권 중 긴 쪽(작법기준 §0). 2026-09-19 설계서에 분량 없어 13,011자 나온 전례 |
| 측정 | 원고 제출 시 **마크업 포함 / 제외 두 값**을 집필 메모에 병기(작법기준 §13) |
| 여유분 | 상한 안에서 **약 400자를 「검증 되돌림으로 정확해지는 값」 몫으로 비워 둔다**(작법기준 §13 보강) — 첫 원고는 3,600자 이하로 낸다 |

## 2. 형태 — 잠정

**탐침 §5가 확인형·정보형이라 이 글은 불안형이 아니라 제도·방법형에 가깝다.** 그래서 서사의 기본값(이야기로만, 표·단계 없음)을 그대로 쓰지 않는다.

| 요소 | 잠정 | 이유 |
|---|---|---|
| 도입 | 3~6문장, 어려운 말 0개. 제도에서 시작하지 않고 **독자가 선 자리**(연말 정산 결과가 궁금하거나 작년에 토해낸 기억)에서 시작 | 회장 기준 §6-4·8 |
| 본문 뼈대 | **독자가 밟는 순서**로 절을 놓는다 — 언제 열리나 → 어떻게 보나 → 나온 숫자를 어떻게 읽나 → 남은 기간에 무엇을 할 수 있나. 순서 확정은 설계 몫 | 탐침 §5의 두 축(시점 확인 · 방법) |
| 단계 나열 | **1회 허용 요청** — 홈택스 조회 경로. 경로는 단계가 정답인 정보 | 설계 지정 필요 |
| 표 | **0~1개.** 쓴다면 반례·조건을 같은 표 안에 넣는 1개 | 작법기준 §13 |
| 사람 말 | 원고 안 인용 자리 **최대 5개**. 청취 인용 중 결과 숫자를 보고 당황한 사람 하나를 축으로 | 작법기준 §7-1 · 7b 인물 기준은 설계 몫 |
| "어?" 한 곳 | 중반 1개 — 미리보기 숫자에 대해 독자가 믿는 것을 뒤집는 사실. **무엇일지는 수집 재료가 나와야 정한다** | 작법기준 §7-4 |
| 마무리 | 체크리스트 또는 순서 복기 + 면책 한 줄. 새 사실 안 꺼냄 | 작법기준 §7-5 |
| 금지 | 인라인 `<style>`·`style=` 없음. 목차·요약 박스 습관적으로 안 넣음 | 페르소나 금지 |

## 3. 형태에 걸리는 제약 — 설계가 알고 있어야 할 것

1. **개시일을 확정 문구로 쓰지 않는다.** 「매년 11월 첫째~둘째 주에 열렸고, 올해 날짜는 국세청 공지 전」으로 쓴다(탐침 §1·§6). 원고에 **개시일을 한 곳에만** 두어 공지가 나오면 그 한 곳만 갱신하게 한다.
2. **목표일 10-19는 개시 전이다 → 올해 화면이 아직 없다.** 조회 경로 절은 작년 화면 기준으로 쓰고 「올해 화면이 열리면 갱신」 자리로 표시한다. 이 절을 원고에서 얼마나 크게 가져갈지는 설계 판단.
3. **트렌드 「지금 값」은 원고에 숫자로 쓰지 않는다**(`02b_도달상한.md` — 진행 중 주 값이 조회 시각마다 바뀜).

## 4. 서사가 이 글을 쓰려면 있어야 하는 것 — 1e 깎기 판단용

**건수는 각 자리가 적는다. 여기는 「원고에 들어갈 자리」만 적는다.**

- 개시일 과거 패턴 1차 출처 — 탐침 §1에 이미 있음(추가 수집 불요, 2024 귀속 1차 보도자료만 미확보)
- 미리보기 결과 화면에 뜨는 **항목명 원문 글자** — 독자가 자기 화면에서 찾는 글자라 해설어로 바꿀 수 없다(작법기준 §12)
- 결과 숫자를 보고 남은 기간에 **바꿀 수 있는 것**의 1차 근거 — "어?" 후보가 여기서 나온다
- 청취 인용 — 원고에 들어가는 것은 최대 5개. 그 이상은 원고에 자리가 없다

```
[서사] 「서사」 — 1d 분량·형태 잠정 제출. 상한 4,000자(첫 원고 3,600자 이하), 확인형·정보형이라 단계 1회·표 0~1개 허용 요청.
        개시일 확정 문구 금지·개시 전 발행이라 조회 경로는 작년 화면 기준 갱신 자리로 둠 — 설계 판단 대상.
        청취·수집·해부 재료 전이라 전부 잠정. 설계서가 오면 설계서가 앞선다.
```
