## 2번 — 상위 블로그 글 원문 확보 (`03_기준글_*.md`·`03_수집기록.md`)

### 구글 검색 경로 — 재두드리지 않는다. WebSearch로 근사한다

`운영/09_조회표.md` 확인(해당 줄만) — **`google.com/search`는 2026-09-22 22:09 재확인 기준 확정 막힘**(쿠키 선행해도 HTTP 200·92,020B인데 `/url?q=` 앵커 0개, `enablejs` 리다이렉트뿐). **재시도하지 않는다** — 두드리면 처음부터 버리는 콜이다.
대체 경로도 확인했다 — **DDG-kr**: CAPTCHA 확정 막힘(조회표 §1 ① 목록, 재두드리지 말라고 명시). **빙**: HTTP 200이나 질의와 무관한 결과(200을 「열렸다」로 쓰면 안 됨). **다음(Daum)**: `w=web`·`w=blog` 버티컬이 HTTP 200에 본문 120~184B 빈 껍데기 — 못 쓴다.
남는 경로는 **WebSearch뿐**이다. **02b_도달상한.md §ⓑ-구글**에서 「실측」이 이미 같은 원칙(조회표 지시대로 대체)으로 `WebSearch("연말정산 미리보기")` 1콜을 썼고 9건 전부 기관·금융사·SNS였다 — **그 콜은 재사용하고 새로 안 친다.**

**명시**: WebSearch 결과 순서는 실제 구글 SERP 1페이지 순위라는 보장이 없다(조회표 동일 문구). `03_기준글_*.md` 상단에 "구글 N위"라고 못 쓴다 — **"WebSearch 결과 M번째(구글 실물 순위 아님)"**로 적는다. 없는 순위를 있는 척 적지 않는다.

| | 값 |
|---|---|
| **어디서** | WebSearch 도구(신규 3콜) + 「실측」 기존 콜 1건 재사용(02b_도달상한.md §ⓑ-구글, 9건, 개인 블로그 0) |
| **무엇을** | 탐침이 확정한 결합어(02_탐침.md §2) 중 확인형·정보형 대표 2종 + 네이버 경쟁자 4편이 실제로 쓴 표제 1종. 사람들이 실제 치는 변형까지 넣으라는 페르소나 원칙을 따른다:<br>① `연말정산 미리보기 2026`(확인형)<br>② `연말정산 미리보기 홈택스 이용 방법`(정보형)<br>③ `2026 연말정산 미리보기`(네이버 경쟁자 4편 표제 그대로 — D-030상 네이버 글 자체는 2번 표본에 못 넣지만, 그 표현으로 구글 쪽에 뜨는 티스토리 글이 있는지는 확인 대상) |
| **몇 건까지** | WebSearch 신규 쿼리 **3콜 상한**(위 3종 그 이상 안 침). 반환 결과는 전건을 `순위\|URL\|코드\|한 줄 근거` 목록표(E1~E6)로 남기고, 그중 E1~E6에 안 걸리는 개인 블로그만 원문을 연다 — 원문 열람도 **상한 5건**, 실제 저장(`03_기준글_*.md`)은 규칙대로 **상위 1~3편**만 |

**위험 고지**: 「실측」의 기존 1콜(대표어 단독)에서 이미 개인 블로그 0/9였다. 신규 3콜도 0이면 **거부권 행사** — "이 키워드에는 기준 삼을 블로그 글이 없다(구글 표본)"로 보고하고 10위권 밖에서 억지로 채우지 않는다. 네이버 4편은 있으나 D-030상 표본에 못 넣는다.

## 5번 — 제도 원문·자료·반례 (`03_사실자료.md`)

탐침이 이미 짚은 갭 둘을 우선 메운다: ① 2024년 귀속(11/5) 1차 보도자료 **직접 인용 미확보** ② 2026년 귀속(이번 시즌) 개시 공지 **미확인**(정상 — 아직 안 나왔을 수 있음, 재확인만). 여기에 반례 탐색(사장 원 전제 "10월 말"을 뒷받침하거나 뒤집는 과거 사례)을 더한다.

`운영/09_조회표.md` 확인 — **`www.nts.go.kr`은 이 표에서 확정 막힘이 아니라 ④(분 단위로 뒤집힘, 다른 검체 2026-09-22 등재: 200 1회 후 000 반복, 그때 타진이라 본문 유실)다.** 계획에 넣는다(막힘 아님), 단 **1c 규칙대로 열리는 순간 본문을 즉시 파일로 저장**(`-o` 지정 저장, 타진 금지 — 유실 재발 방지). `korea.kr`은 루트만 열림·검색 경로는 000 확정이므로 **검색은 안 쓰고 탐침이 이미 인용한 개별 URL만** 연다.

| **어디서** | ① `www.nts.go.kr`(국세청 — 보도자료·서비스 공지 1차) ② `www.korea.kr`(정책브리핑 — 탐침이 이미 인용한 개별 기사 URL만, 검색 경로 안 씀) ③ `hometax.go.kr`(홈택스 — 서비스 화면·이용안내 1차) |
| **무엇을** | ① 국세청: (a) 2026년 귀속 개시 공지 최신 재확인 1건 (b) 2024년 귀속(11/5) 1차 보도자료 원문 1건 — 탐침 갭 메우기 (c) 과거 미확인 연도(2018~2023, 6개년) 개시 공지 원문 — 패턴("매년 11월 첫째~둘째 주") 반례 탐색용, **10월에 개시한 해가 있는지가 핵심 질문**. 여는 김에 국세청이 공식 발표한 환급 관련 통계(평균 환급액 등)가 있으면 같은 방문에서 같이 저장(사례 자료, 별도 상한 안 둠)<br>② 정책브리핑: 탐침이 §1에서 인용만 하고 원문 미저장인 `m.korea.kr/news/policyNewsView.do?newsId=148954467` 1건 저장(1c 규칙 소급 적용)<br>③ 홈택스: 연말정산 미리보기 서비스 소개·이용 방법 1차 화면 2건 |
