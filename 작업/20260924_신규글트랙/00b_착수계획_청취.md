# 00b 착수계획 — 「청취」 몫

근거로 연 것: `02_탐침.md` §1·§2·§5·§6 · `02_탐침_증빙/kin_p1.html`~`kin_p5.html`(지식iN 원문 50건, 탐침이 이미 확보 — 재조회 안 함) · `운영/10_공정순서.md` 1d 절.

**`03_기준글_*.md`·`03_해부.md`는 아직 없다.** 2번(수집)·3번(해부)이 1d보다 뒤라 존재할 수 없다 — 이기는 지점은 3번이 나오면 그때 반영한다. 지금은 탐침의 검색의도 분류(§5)만 갖고 짠다.

## 어디서

| 순 | 경로 | 비고 |
|---|---|---|
| 1 | 지식iN 이미 확보한 5페이지 50건 제목(탐침 증빙, `kin_p1.html`~`kin_p5.html`) | **재조회 안 함** — 이 목록에서 후보만 고른다 |
| 2 | 후보의 지식iN 상세 페이지(`kin.naver.com/qna/detail.naver?...docId=`) | 제목만으로는 감정이 안 보인다 — 질문 본문·답변까지 열어야 함 |
| 3 | 지식iN 결합어 확장 검색 — 탐침 §2의 "환급금 미리보기"·"홈택스 이용 방법" 갈래 | 50건 목록에 없는 결이 5인을 못 채울 때만 |

네이버 카페·그 밖 커뮤니티는 1차로 열지 않는다 — 지식iN 50건 안에 확인형·정보형·환급 갈래가 이미 섞여 있다(탐침 §2). 그래도 5인이 안 채워지면 그때 사장에게 확장을 묻는다.

## 인용 몇 건까지

| 항목 | 상한 |
|---|---|
| 지식iN 상세 페이지 열람 | **10건** (50건 제목 중 후보를 추려서 연다) |
| 결합어 확장 검색으로 새로 여는 페이지 | **3건** (10건으로 5인이 안 채워질 때만) |
| **총 상한** | **13건.** 넘기려면 사장에게 다시 묻는다 |

## 인물 몇 인

**5인.** (7b 설계 사전검 기준 — 인물 5명 미만은 되돌림 사유)

잠정 배분(탐침 §5 검색의도 비중 근거, 상세 페이지 실물 읽고 조정 가능):

| 결 | 인원 | 탐침 근거 |
|---|---|---|
| 확인형(올해도 여나·언제부터·언제까지) | 2인 | §5 "비중 크다" |
| 정보형(보는법·홈택스 이용 방법) | 2인 | §5 "방법을 모르는 사람이 많다" |
| 결과 숫자 보고 놀란 쪽(기납세금 0원·예상 환급액) | 1인 | 지식iN 50건 목록에 해당 제목 다수 확인(`kin_p3.html`·`kin_p4.html`) |

거래형(§5 "약하다")은 인물로 세우지 않는다 — 탐침이 이미 약하다고 짚었다.

```
[청취] 「청취」 — 1d 착수계획 제출. 어디서: 지식iN(탐침이 이미 확보한 50건 목록 재사용 + 상세 열람 10건 + 결합어 확장 3건).
        인용 총상한 13건. 인물 5인(확인형2·정보형2·환급당황1, 잠정 배분).
        03_기준글·03_해부는 1d보다 뒤 단계 산출물이라 아직 없음 — 이기는 지점 반영은 3번 이후, 실제 인물 배분도 그때 다시 볼 수 있음.
```
