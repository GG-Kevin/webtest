## 왜 이 형태인가

「진행」 배정값을 그대로 조판했다 — 배경 아이보리-앰버(248,238,214), 좌측
정렬, 주제어 상단. 텍스트는 전부 `06_썸네일문구_11.md`에 있는 표현만
가져왔고 「지면」이 새로 지은 문장은 없다.

- **주제어 "VI"**: 좌상단, ExtraBold 420pt(h=297) — 이 장 전체에서 가장 큰
  글자. 확정 제목("VI가 떴다고 파는 게 맞을까요")과 본문 근거 8행 인용문에
  반복해서 나오는 그 단어이고, 숫자·날짜가 아니다(회장 공통사항 직결).
- **킥커 "VI(변동성완화장치)"**: `06_썸네일문구_11.md` 표제 자체의 표현
  ("`/11` VI(변동성완화장치)")을 그대로 옮겼다. 새로 지은 설명이 아니다.
- **감속 바(5개, 좌→우로 짧아짐)**: 장식 도형(데이터 아님) — 문구 "막는
  게 아니라, 늦추는 겁니다"의 시각 은유. 첫 막대만 번트오렌지로 강조해
  "사건 지점"을 표시했다. 화살표·꺾은선 그래프 아님.
- **캡션 "속도만 늦추는 장치"**: 본문 근거 8행 인용문 "VI는 방향을 바꾸는
  장치가 아니라 속도만 늦추는 장치입니다"의 부분 발췌. 새 문장 아님.
- **헤드라인**: 확정 썸네일 문구 "막는 게 아니라, 늦추는 겁니다"를 2줄로
  줄바꿈만 했다. 문구 자체는 무수정.

색상축(청 vs 웜브라운/딥틸)과 정렬(중앙 vs 좌)·구조(캡슐 vs 감속 바)가

**글자 잘림 센 명령어(재현 가능)**:
```bash
python3 -c "
from PIL import Image
im = Image.open('11.png').convert('RGB'); w,h=im.size; px=im.load(); bg=px[2,2]
def d(p): return abs(p[0]-bg[0])+abs(p[1]-bg[1])+abs(p[2]-bg[2])>40
ys=[y for y in range(h) if any(d(px[x,y]) for x in range(0,w,2))]
xs=[x for x in range(w) if any(d(px[x,y]) for y in range(0,h,2))]
print('y',min(ys),max(ys),'margin_top',min(ys),'margin_bottom',h-1-max(ys))
print('x',min(xs),max(xs),'margin_left',min(xs),'margin_right',w-1-max(xs))

```
