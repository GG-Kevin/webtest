## 1. 그래픽 지침 — 어느 안을 썼는가

**1안(산식 타이포)을 택함.** 근거: `본문/글2.txt` **12행** 「36 더하기 10은 46입니다」를 계산식 「36 + 10 = 46」 그대로 확대해 그렸다. 시간에 따라 변하는 계열을 전혀 그리지 않았다 — 세 숫자(36·10·46)는 전부 본문에 실재하는 이산값이고, 그 사이를 잇는 막대·선은 하나도 없다. 2안(취소선 정정)·3안(45칸 균일 채움)은 쓰지 않음 — 1안이 반려 사유(가짜 추세)를 가장 직접적으로 차단한다고 판단(산식은 "언제나 참인 등식"이라 시계열로 오독될 여지가 구조적으로 없음).

산식 아래 라벨 3개("경과일수"·"연속 필요"·"46번째 거래일")는 새 주장이 아니라 본문 11행("경과일수")·12행("10일 연속")·확정 제목("46번째 거래일")에 있는 단어를 그대로 가져다 숫자 밑에 붙인 것 — 수치·문구 둘 다 새로 지어내지 않았다.

### 8-2. 새 배경이 왜 이 값인가 — D-139 §2 신설 규칙 적용

**규칙: 새 배경은 이미 만든 전편 배경과 채널차 합(|ΔR|+|ΔG|+|ΔB|) 각각 30 이상.**

```python
def diff(a,b): return sum(abs(x-y) for x,y in zip(a,b))
new=(230,214,178)
# vs /27 (247,245,240) → 110
# vs /8  (237,241,245) → 101
# vs /28 (20,20,20)    → 562
```

| vs | `/27 (247,245,240)` | `/8 (237,241,245)` | `/28 (20,20,20)` |
|---|---|---|---|
| 채널차 합 | **110** | **101** | **562** |

셋 다 30 이상 — 여유 있게 통과. 직전 반려본(`(247,242,231)`)은 R이 `/27`과 완전히 같아 12까지 떨어졌던 것과 달리, 이번 값은 R·G·B 세 채널 모두를 동시에 이동시켰다.

**톤 선택 근거**: 라이트·웜 계열은 유지(D-139 §4 — "아이보리를 쓰지 마라"가 아니라 겹침만 문제였음을 확인). 다만 아이보리/오프화이트 축에서 벗어나 채도를 올린 **웜 샌드(sand)** 톤으로 옮겨 `/27`(거의 무채색에 가까운 라이트그레이)·`/8`(쿨톤 라이트블루그레이) 둘 다와 색상·채도·명도 세 축에서 동시에 벌어지게 했다.

### 8-3. 명도차 확인 — 텍스트 판독 조건 재확인

실제 렌더(`2.png`)에서 색상 기반 bbox로 교차 확인(bands.py 원시 밴드는 등식 행 전체를 하나로 묶어 함정이 있으므로 색상별로 분리 측정):

```bash
python3 - <<'PYEOF'
from PIL import Image
img = Image.open("2.png").convert("RGB")
px = img.load(); w,h = img.size
def bbox_color(target, tol, y0, y1, x0=0, x1=None):
    x1 = x1 or w
    minx,miny,maxx,maxy=w,h,0,0; found=False
    for y in range(y0,y1):
        for x in range(x0,x1):
            p=px[x,y]
            if abs(p[0]-target[0])+abs(p[1]-target[1])+abs(p[2]-target[2])<tol:
                found=True
                minx,maxx=min(minx,x),max(maxx,x)
                miny,maxy=min(miny,y),max(maxy,y)
    return (minx,miny,maxx,maxy) if found else None
terra46 = bbox_color((178,61,33),20, 400,800, 300,1000)
print("핵심 숫자 46(terracotta) 실측 h =", terra46[3]-terra46[1]+1)
hl2 = bbox_color((26,23,21),20, 210,290)
print("헤드라인2 실측 h =", hl2[3]-hl2[1]+1)
PYEOF
```
