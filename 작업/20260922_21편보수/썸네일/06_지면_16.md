## 왜 이 형태인가

「진행」 배정값 그대로 조판했다 — 배경은 자주빛으로 축을 분리한 딥
플럼(90,10,60), 좌측정렬, 주제어는 하단. 문구는 전부 「포착」 문서 또는
본문 직접 인용이고 「지면」이 새로 지은 문장은 없다.

- **주제어 "ISA"**: 확정 제목 두 번째 단어(무수정), ExtraBold 400pt,
  캔버스 하단 좌측정렬. 이 장 전체에서 가장 큰 글자 — 회장 공통사항
  ("가장 중요한 게 가장 크고 잘 보여야지") 직결.
- **킥커 "생산적금융"**: 확정 제목 첫 단어(무수정), 상단.
- **헤드라인**: 확정 썸네일 문구 "비과세 한도, 이번엔 없습니다"를 2줄로
  줄바꿈만 했다 — 문구 자체는 무수정.
- **보조 태그 "한도 없이 전액 비과세"**: 본문 1행·19행에 동일하게
  등장하는 문구를 그대로 잘라 왔다(두 줄 다 이 8글자 연속 문구를
  포함 — 아래 확인 명령 참조). ISA 바로 위, 주제어를 뒷받침하는
  위치에 배지로 배치했다.
- **노란 계열 완전 배제**: 배지 배경은 크림(245,235,240), 글자는
  플럼(90,10,60) — 22장 틀의 "노란 배지"와 다른 색조합.

### 검사 1 — 가장 중요한 것이 가장 큰가

분모: 그 장에 그려진 **글자**의 잉크 행 높이 최댓값(도형 제외). 분자: 주제어
"ISA"(제목에서 그대로, 숫자·날짜 아님).

**센 명령어(재현 가능)**:
```bash
cd /home/user/webtest/작업/20260922_21편보수/썸네일/
python3 - <<'EOF'
from PIL import ImageFont
F = "/home/user/webtest/자산/폰트/Pretendard-%s.otf"
def f(w,s): return ImageFont.truetype(F%w,s)
def h(t,w,s):
    bb=f(w,s).getbbox(t); return bb[3]-bb[1]
items=[("킥커 생산적금융","Bold",42,"생산적금융"),
("헤드1 비과세 한도,","Bold",68,"비과세 한도,"),
("헤드2 이번엔 없습니다","Bold",68,"이번엔 없습니다"),
("태그 한도없이전액비과세","Bold",34,"한도 없이 전액 비과세"),
("주제어 ISA","ExtraBold",400,"ISA")]
for n,w,s,t in items: print(n, h(t,w,s))
EOF
```

**결과**:

| 항목 | h |
|---|---|
| **ISA(주제어)** | **291** |
| 헤드1 "비과세 한도," | 70 |
| 헤드2 "이번엔 없습니다" | 62 |
| 킥커 "생산적금융" | 38 |
| 태그 "한도 없이 전액 비과세" | 32 |

다음으로 큰 요소(헤드1, h=70)는 주제어의 24%다. **비율 = 291/291 = 1.00**
(≥0.8 통과).

```bash

from PIL import Image
im = Image.open('16.png').convert('RGB'); w,h=im.size; px=im.load(); bg=px[2,2]
def d(p): return abs(p[0]-bg[0])+abs(p[1]-bg[1])+abs(p[2]-bg[2])>40
ys=[y for y in range(h) if any(d(px[x,y]) for x in range(0,w,2))]
```
