## 왜 이 형태인가

「포착」 지침을 그대로 조판했다 — 확정 제목·썸네일 문구 전부 무수정.

- **주제어 "휴장"**: 확정 제목("추석 주식시장 휴장은 24일·25일…")의 핵심어.
  이 글이 무엇에 관한 글인지 말해주는 단어이고, 캔버스 최상단·좌측정렬,
  ExtraBold 300pt로 이 장 전체에서 가장 큰 글자다(회장 공통사항 직결).
- **헤드라인 2줄**: 확정 썸네일 문구 "9월 23일에 팔아도, 돈은 29일에야
  들어옵니다"를 줄바꿈만 해서 좌측정렬로 얹었다. 문구 자체는 무수정.
- **가로 3점 타임라인**: 본문 66행 원문("9월 23일(수) 매도 → 다음 영업일은
  9월 28일(월) → 출금 가능일 9월 29일(화)")을 그대로 시각화했다. 날짜·라벨
  전부 66행 직접 인용이고 「지면」이 새로 지은 문장은 없다. 마지막 점(9월
  29일·출금 가능일)만 코랄로 강조해 "정작 놓치기 쉬운 날짜"를 이미지로도
  가리킨다 — 헤드라인이 파는 것과 같은 지점이다.
- **좌·우 끝점 라벨은 안쪽으로만 정렬**: 처음 조판 시 양끝 날짜 텍스트가
  가운데정렬로 dot 위에 얹히면서 캔버스 좌우 경계를 3~4px 벗어나
  잘리는 것을 검사4에서 잡아 좌측점은 왼쪽정렬, 우측점은 오른쪽정렬로
  즉시 수정했다(아래 검사4 참조) — 이 턴 안에서 직접 고쳤다.

`/5`와 같지만 `/5`는 2패널 병치이고 시간 흐름을 보여주지 않는다.

| 글자 잘림 | 0건 — 아래 센 명령어로 확인(초안에서 걸려 즉시 재수정) |

**글자 잘림 센 명령어(재현 가능)**:
```bash
python3 -c "
from PIL import Image
im = Image.open('22.png').convert('RGB'); w,h=im.size; px=im.load(); bg=px[2,2]
def d(p): return abs(p[0]-bg[0])+abs(p[1]-bg[1])+abs(p[2]-bg[2])>40
ys=[y for y in range(h) if any(d(px[x,y]) for x in range(0,w,2))]
xs=[x for x in range(w) if any(d(px[x,y]) for y in range(0,h,2))]
print('y',min(ys),max(ys),'margin_top',min(ys),'margin_bottom',h-1-max(ys))
print('x',min(xs),max(xs),'margin_left',min(xs),'margin_right',w-1-max(xs))
"
```
결과: y 96~911(상단여백96·하단여백168), x 73~974(좌여백73·우여백105).
캔버스 1080×1080 안쪽에 전부 있다.

**초안에서 실제로 걸렸던 것**: 타임라인 좌·우 끝점 날짜("9월 23일(수)",
"9월 29일(화)")를 dot 중심 가운데정렬로 그렸을 때 x범위가 0~1079로
찍혀 캔버스 가장자리(좌우 각 3~4px)를 벗어나 잘리는 것을 이 센 명령어가
바로 잡아냈다. 문구를 줄이지 않고 **정렬 방식만** 바꿔 해결했다 —
좌측 끝점은 왼쪽정렬(점 기준 오른쪽으로만 자라게), 우측 끝점은
오른쪽정렬(점 기준 왼쪽으로만 자라게), 중앙점만 가운데정렬 유지.
재검 결과 위 x 73~974로 전부 안쪽에 들어왔다.
