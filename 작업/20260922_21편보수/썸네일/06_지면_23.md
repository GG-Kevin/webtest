## 왜 이 형태인가

「포착」 지침이 데이터 계열 없음을 명시하고 "두 숫자를 나란히 놓고
대비하는 장치만 쓴다"고 구조를 지정했다 — 50개(거래소 예상)와 150개
(실제 추산)를 오르내리는 그래프로 잇지 않고 **2블록 병치**로 대비시켰다.
`make7.py`의 좌표·레이아웃 함수는 복사하지 않았다 — `/7`은 좌우 대칭
2블록+세로 시간경계선(정렬축 대칭, 주제어 상단)이었고, `/23`은 **우측
정렬 비대칭 2블록(경계선 없음)+주제어 하단**으로 새로 짰다.

- **주제어 "관리종목"**: 확정 제목("관리종목 36개, ...")의 첫 단어를
  그대로 썼다. 새로 지은 단어가 아니다. 캔버스 최하단, ExtraBold
  250pt, 이 장 전체에서 가장 큰 글자 — 회장 공통사항("가장 중요한 게
  가장 크고 잘 보여야지") 직결.
- **2블록**: 좌 "거래소 예상 / 50개"(무채 크림 패널, 출력색만 대비) /
  우 "실제 추산 / 150개"(경고색 러스트 패널, 숫자도 더 크게) — 크기
  자체로 "예상보다 실제가 크다"는 관계를 전달한다. 숫자(50개·150개)는
  주제어보다 항상 작게 유지했다(주제어 h=225 vs 최대 숫자 h=83).
- **캡션 "당초 예상의 3배"**: 06_썸네일문구_23.md의 [본문 근거]가
  본문 92행에서 이미 직접 인용한 문장 그대로 옮겼다 — 「지면」이 새로
  지은 문장이 아니다(2026-09-23 재발 방지 사항 준수).
- **헤드라인**: 확정 썸네일 문구 "거래소 예상 50개, 실제 추산은
  150개입니다"를 쉼표 기준 2줄로 줄바꿈만 했다. 문구 자체는 무수정.
- **배경/정렬축/주제어 위치**: 「진행」 배정(페일 스카이-틸·우측·하단)을
  그대로 따랐다. 배정된 (206,231,236)은 `/8` 쿨그레이(237,240,245)와
  채널차 최대 31로 30 턱걸이였다 — 청록을 (176,218,226)으로 더 진하게
  조정해 `/8`과의 채널차를 61로 확보했다(아래 검사3).

### 검사 3 — 서로 다른가 (D-105 §8)

배경 채널차(단일 최대 채널, `/7` 방식 그대로):

```bash
python3 -c "
from PIL import Image
im = Image.open('23.png').convert('RGB')
new = im.getpixel((5,5))
existing = {'/2':(230,214,178), '/5':(56,18,26), '/6':(20,42,35), '/7':(40,20,70), '/8':(237,240,245)}
for k,v in existing.items():
    d = tuple(abs(a-b) for a,b in zip(new,v))

"
```
