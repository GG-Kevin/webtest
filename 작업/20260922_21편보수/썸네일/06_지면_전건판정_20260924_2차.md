## 4. 검사 3 — 서로 다른가 (기완료 5장 + 12편, D-105 §8)

배경 RGB 픽셀 `(5,5)` 실측, 전편 대비 최소 채널차:

```bash
python3 -c "
from PIL import Image
order = ['2','5','6','7','8','11','12','13','16','17','18','19','20','21','22','23','25']
rgb = {n: Image.open(n+'.png').convert('RGB').getpixel((5,5)) for n in order}
seen=['2','5','6','7','8']
for n in order[5:]:
    diffs=[(sum(abs(a-b) for a,b in zip(rgb[n],rgb[m])), m) for m in seen]
    diffs.sort(); print(n, rgb[n], 'min diff', diffs[0]); seen.append(n)
"
```

결과 — 12편 전부 기존 전편 대비 **최소 채널차 41 이상**(가장 가까운 쌍: `/19`
vs `/13` 41, `/22` vs `/6` 41). 정확히 같은 배경 0건. 도장처럼 같은 배경·정렬·
포인트색 조합이 3장 이상 연속되지 않는다(정렬축은 좌/우/중앙이 고르게 섞여
있고, 색상축도 아이보리·틸블루·피치·플럼·민트·토프·라일락·올리브·베이지탠·
차콜퍼플·스카이틸·브릭마룬으로 12편 전부 다른 계열).

남색(navy) 배경 0건 — 어두운 배경들(`/12·16·18·20·22·25`)도 각각 G채널 지배
(`/20`), R≈G≈B 무채색(`/22`), 마젠타·브릭 색상축(`/16·25`) 등으로 22장 틀의
남색과는 다른 축에 있다.
