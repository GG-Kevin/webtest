## 새 검사 — 165px 축소 실물 육안판정 (「지면」 설계)

사장이 준 것은 방향(165px 폭 실물로 읽히는가)뿐, 항목·측정법은 검사자
몫이다(D-149 §2, D-042). 「지면」이 다음 절차로 정한다.

**절차:**
1. 완성 PNG(1080×1080)를 회장이 보여준 실제 노출 폭(`17.png` 2열 그리드,
   장당 약 165px)에 맞춰 `Image.resize((165,165), LANCZOS)`로 축소한다 —
   진짜 배포 스케일과 같은 리샘플링.
2. 그 165px 실물을 4배(`NEAREST`, 재보간 없이 순수 확대)로 키워 **직접
   본다**(Read 도구로 실제 열람). 이것이 **최종 판정**이다 — "무슨 말인지
   읽히는가"를 사람이 본다.
3. 보조 지표로 `bands.py`가 잰 1080px 원본 잉크 행 높이에 `165/1080`을
   곱해 **165px에서의 절대 픽셀 높이**를 구한다. 비율이 아니라 절대값이며,
   다른 값을 줄여서 점수를 올릴 수 없다(분모가 없다).
4. 경험적 기준선: 이번 산출물에서 **9px 안팎이 읽히는 하한**으로
   관찰된다 — 구판 캡션(36pt, 165px 환산 약 5.5px)은 실제 배포 화면
   (`17.png` 확대본)에서 형체만 있고 글자로 안 읽혔고, 신판의 가장 작은
   텍스트(연결어·헤드라인, 165px 환산 8.9~10.1px)는 3에서 육안으로 읽힌다.
   이 하한은 이번 1개 서체(Pretendard Bold/ExtraBold) 실측치이며 다음
   장에 그대로 이식하는 규칙으로 세우지 않는다 — 장마다 다시 165px
   실물로 본다.

**결과(신판, `25.png`):**

| 블록 | 1080px 잉크 h | 165px 환산 | 3의 육안판정 |
|---|---|---|---|
| 유상증자(주제어) | 180 | 27.5px | 즉시 읽힘 |

## 왜 이 형태인가 — 범주어 단독 금지(D-149 §5) 집행

회장 지적 "유상증자 뭐?"는 165px에서 **범주어("유상증자")만 읽히고
정보는 안 읽혔다**는 뜻이다. 구판은 범주어(240pt) 바로 아래 64pt
헤드라인으로 점프했고, 165px에서 사실상 범주어 1단만 살아남았다.

`/5`가 회장이 "맘에 든다"고 한 구조 — **확정 제목 원문에서 그대로 이어
붙인 연결어**로 범주어를 문장 첫머리로 만든 것(관리종목+지정되면) —
를 그대로 이식했다. **새 카피는 짓지 않았다.**

1. **핵심어 "유상증자"** — 확정 제목 첫 단어, 최대 글자(ExtraBold), 최상단.
2. **연결어 "악재인지 아닌지는"** — 확정 제목("유상증자, 악재인지
   아닌지는 '자금 용도' 한 칸에 있습니다") 391행 원문에서 그대로 옮긴
   세그먼트. 1)과 이어 "유상증자, 악재인지 아닌지는"으로 한 문장처럼
   읽힌다 — 지면이 지은 문장이 아니라 확정 제목을 자른 것.
3. **통계 배지 "20%"** — 확정 썸네일 문구("20% 급락, 사실은 매도가
   아니라 조정입니다")의 첫 세그먼트를 짧은 숫자라는 이유로 분리해
   색 배지에 키웠다. `/23`의 "50개/150개" 박스와 같은 원리(짧은 문자열은
   큰 글자로도 165px에서 뭉개지지 않는다) — 문구를 새로 짓지 않고
   확정 문구를 줄바꿈·색 배지로만 재조판했다(조판은 「지면」 책무,
   D-149 이전 규칙 그대로 유지).
4. **나머지 확정 문구 "급락, 사실은 매도가 아니라 조정입니다"** — 무수정,
   2줄로 줄바꿈만.

구판의 캡션(본문 62행 인용)은 뺐다 — 헤드라인이 이미 "조정입니다"로
같은 내용을 말해 165px에서 캡션은 읽히지도 않으면서 중복이었다(캡션은
「지면」이 얹은 보조 요소였지, 「포착」 확정 문구가 아니었다 — 확정
문구·확정 제목은 전부 그대로 살아 있다).

## 직전 3편(`/21·22·23`)과 다른가

| 편 | 정렬 | 주제어 위치 | 구조 |
|---|---|---|---|
| `/21` | 좌측형 | 하단 | 킥커+헤드라인+시간대바+화살표쌍 |
| `/22` | 좌측정렬 | 상단좌측 | 헤드라인+3점 타임라인 |
| `/23` | 우측정렬 | 하단우측 | 헤드라인+2블록 비교박스+캡션 |
| `/25`(신판) | **중앙정렬** | **최상단** | **주제어+연결어(2단 문장) + 단일 숫자배지 + 헤드라인** |

정렬축(중앙 vs 좌/우)·주제어 위치(최상단 vs 하단/좌상단)·핵심 장치
(단일 중앙 배지 vs 화살표쌍/3점 타임라인/2블록 비교)가 셋 모두와
겹치지 않는다.

## 금지 항목 재확인

| 항목 | 결과 |
|---|---|
| 본문에 없는 약속 | 0건 — 전부 확정 제목·확정 썸네일 문구 원문, 새 문장 0건 |
| 남의 이미지 | 0건 — Pillow 도형·타이포만 |
| 글자 잘림 | 0건 — 잉크 bbox가 캔버스(1080×1080) 안쪽, 아래 확인 |

```bash
python3 -c "
from PIL import Image
im = Image.open('25.png').convert('RGB'); w,h=im.size; px=im.load(); bg=px[2,2]
def d(p): return abs(p[0]-bg[0])+abs(p[1]-bg[1])+abs(p[2]-bg[2])>40
ys=[y for y in range(h) if any(d(px[x,y]) for x in range(0,w,2))]
xs=[x for x in range(w) if any(d(px[x,y]) for y in range(0,h,2))]
print('y', min(ys), max(ys), 'x', min(xs), max(xs))
"
```
