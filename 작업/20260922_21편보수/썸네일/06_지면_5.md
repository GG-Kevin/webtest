### 2-1. bands.py 함정 — 이 장에도 있었다

`python3 bands.py 5.png` 원시 출력에는 169px 밴드 외에 **`y700-910 h=211`** 밴드가 추가로 잡힌다. 이 밴드를 "글자"로 잘못 읽으면 비율이 169/211=0.80으로 아슬아슬하게 걸치거나(문턱값 기준으로는 통과지만) 다른 해석에서는 반려선에 걸릴 수 있는 애매한 값이 된다. **`make5.py` 소스로 직접 대조한 결과 이 밴드는 글자가 아니라 두 색상 패널(`rounded_rectangle`, PANEL/CORAL 채움색)의 잉크 연속 구간이다.**

```bash
python3 - <<'PYEOF'
from PIL import Image
img = Image.open("5.png").convert("RGB"); px = img.load(); w,h = img.size
def bbox_color(target, tol, y0, y1):
    minx,miny,maxx,maxy=w,h,0,0; found=False
    for y in range(y0,y1):
        for x in range(w):
            p=px[x,y]
            if abs(p[0]-target[0])+abs(p[1]-target[1])+abs(p[2]-target[2])<tol:
                found=True
                minx,maxx=min(minx,x),max(maxx,x); miny,maxy=min(miny,y),max(maxy,y)
    return (minx,miny,maxx,maxy) if found else None
PANEL=(76,30,38); CORAL=(255,122,96)
print("panel(왼쪽, A종목) bbox", bbox_color(PANEL,10,690,920))
print("panel(오른쪽, B종목) bbox", bbox_color(CORAL,10,690,920))
PYEOF
# panel(왼쪽, A종목) bbox (72, 700, 522, 910)
# panel(오른쪽, B종목) bbox (558, 700, 1008, 910)
```

두 패널 모두 y700-910(h=211)로 폭 450px 사각형 전체가 균일하게 채워진 배경색이다 — 텍스트 글리프가 아니라 `rounded_rectangle` 도형(장식 블록). bands.py는 "배경과 다른 색이 연속된 구간"만 보므로 도형 채움과 글자를 구분하지 못한다. **이 211px 밴드는 제외 대상.**

### 2-3. 실측(색상 기반 bbox) 교차 확인

```bash
python3 - <<'PYEOF'
from PIL import Image
img = Image.open("5.png").convert("RGB"); px = img.load(); w,h = img.size
def bbox_color(target, tol, y0, y1, x0=0, x1=None):
    x1 = x1 or w
    minx,miny,maxx,maxy=w,h,0,0; found=False
    for y in range(y0,y1):
        for x in range(x0,x1):
            p=px[x,y]
            if abs(p[0]-target[0])+abs(p[1]-target[1])+abs(p[2]-target[2])<tol:
                found=True
                minx,maxx=min(minx,x),max(maxx,x); miny,maxy=min(miny,y),max(maxy,y)
    return (minx,miny,maxx,maxy) if found else None
CREAM=(244,236,228)
kw = bbox_color(CREAM,15,80,280,0,900)
print("관리종목(cream) 실측 h =", kw[3]-kw[1]+1)
PYEOF
# 관리종목(cream) 실측 h = 155
```

색상 임계값 차이로 pt계산(169)과 실측(155)에 소폭 오차가 있으나(안티앨리어싱 경계 픽셀 포함 여부), **어느 기준으로도 패널 211px보다 작고, 다른 모든 실제 글자(헤드라인 83px 이하)보다는 크다.** 핵심어가 도형을 제외한 실제 텍스트 중 최대라는 결론은 두 측정법 모두 일치.
