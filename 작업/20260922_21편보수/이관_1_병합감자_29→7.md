## 0. 먼저 — 꼬리 ③이 경고한 중복을 **한 쪽으로 정했다**

꼬리 ③의 ⚠: *"`/9` §5의 「액면병합」은 ①에서 `/2`로 옮기기로 한 고유분 ⓑ와 같은 것일 수 있다."*

**열어 봤고, 같은 절이다. 정한 결과는 이렇다.**

| | 보낸 곳 | 안 보낸 곳 |
|---|---|---|
| **`/9` §5 「액면병합하면 피할 수 있나 — 대부분은 못 피합니다」** | **`/2`** (고유분 ⓑ로 흡수) | **`/7`** |

**이유 한 줄** — `/9` §5의 논지는 *"병합은 주가는 올려도 **시가총액**은 그대로다"*이고, 이 문장은 **시가총액 요건이 같은 글 안에 있어야만 말이 된다.** `/2`는 이번에 이관 2(시총 상향 일정표)를 받아 시가총액 요건을 싣는 글이 되지만, `/7`에는 시가총액 요건이 없어 그 문장이 홀로 서지 못한다. **한 절을 두 곳으로 보내면 중복을 지우려다 새 중복을 만든다**(꼬리 ③ 경고). 그래서 `/2` 한 곳으로만 보냈다.

**그러므로 이 파일에 담긴 것은 `/2`에서 잘라낸 것뿐이다. `/9`에서 잘라낸 것은 없다.**

## 1. `/2`에서 잘라낸 원문 — **그대로** (묶음2가 `/7`에 붙인다)

잘라낸 자리: `/2` 절 「**회사가 병합했으니 끝났다고 들으셨다면 — 공시 368건을 열어봤습니다**」 안, 문단 *"그 움직임이 지금은 족쇄입니다"*부터 *"최근 1년 안에 병합·감자 이력이 있을 때만입니다."*까지 **4블록**(p·blockquote·p·p).

```html
<p style="margin:0 0 19px;line-height:1.85;">그 움직임이 지금은 <b>족쇄</b>입니다. 금융위 원문.</p>

<p style="margin:0 0 19px;line-height:1.85;"><b>미리 병합해 둔 회사는 그 이력 때문에 정작 지정된 뒤에 병합 카드를 못 씁니다.</b> 다만 「최근 1년」의 기산점은 조문을 못 열어 확인 못 했습니다.</p>
```

### 왜 이 블록이 `/7`로 가야 하나 — 묶음2가 그대로 쓸 근거

**`/7` §4 「관리종목 지정 후에는 막힙니다」의 표가 지금 이 내용을 1차 근거 없이 싣고 있다.** 라이브 `/7` §4 표 3행(`지정 전 / 지정 후 최근 1년 내 이력 / 지정 후 병합 비율`)이 바로 위 금융위 (1)(2)를 풀어 쓴 것인데, **`/7` 어디에도 그 원문이 없다.** 원문은 `/2`에만 있었다. 이 블록이 `/7`로 가면 **`/7`이 자기 표의 근거를 갖는다.**

**센 명령어**(`/7`에 원문이 없음):
```
grep -c '10:1을 초과하는 주식병합' 폐기/20260922_실측_라이브/p7.html   → 0
grep -c '10:1을 초과하는 주식병합' 폐기/20260922_실측_라이브/p2.html   → 1
```

## 2. 붙일 때 묶음2가 알아야 할 것 — 셋

**① 앞 문장 「그 움직임이 지금은 족쇄입니다. 금융위 원문.」은 `/2`의 앞 문맥(4월 98건 병합 러시)을 받는 말이다.** `/7`에는 그 앞 문맥이 없다. **`/7`에 붙일 때 이 한 문장은 `/7`의 앞 문맥에 맞게 다시 쓴다** — 나머지 세 블록(원문 blockquote + 해설 2문단)은 **한 글자도 고치지 않는다.**

**② 「최근 1년」의 기산점은 확인 못 한 채다.** 그 한 줄(*"다만 「최근 1년」의 기산점은 조문을 못 열어 확인 못 했습니다."*)을 **빼지 마라.** 「모른다」를 적은 문장이지 변명이 아니다. 빼면 `/7`이 조문을 연 것처럼 읽힌다.

**③ `/7`의 기존 176건 서술과 겹치지 않는다.** `/7` §3의 *"2026년 1월 말부터 5월 중순까지 병합 공시가 176건"*은 **공시 건수**이고, 이 블록은 **금지 조항**이다. 둘 다 남겨도 중복이 아니다.

## 3. `/2`에 남긴 것 — 묶음2가 다시 손댈 필요 없다

잘라낸 자리에 **대체 문장 1개 + `/7` 문맥 링크**를 본문 문장 안에 녹여 넣었다(목록·말미 모음 아님).

```html
<p style="margin:0 0 19px;line-height:1.85;">그 움직임이 지금은 <b>족쇄</b>입니다. 관리종목으로 지정되고 나면 병합·감자 카드 자체가 막히는데, <a href="https://moneyproducer.co.kr/7" style="color:#0a6350;font-weight:600;border-bottom:2px solid #8fd0bb;text-decoration:none;padding-bottom:1px;">막히는 조건이 「최근 1년 안에 병합·감자 이력이 있을 것」과 「10:1을 초과하는 비율」 둘</a>이라 앞에서 계산기를 두드린 그 「감자 10:1」은 정작 금지에 안 걸립니다. 걸리는 쪽은 <b>미리 손을 써 둔 회사</b>입니다. 카드를 먼저 쓴 값을, 정작 몰린 뒤에 못 쓰는 것으로 치릅니다.</p>
```

**앵커가 `/7`의 주장과 같은 말이다**(작법기준 §13 보강3). 링크를 빼도 문장이 완결되고, 링크가 있으면 독자가 한 걸음 더 간다.

**대체 후 `/2`의 순증**: 312자 → **157자** (−155자). 같은 명령으로 셌다.
