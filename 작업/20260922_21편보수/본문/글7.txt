<div class="contents_style"><p style="margin: 0 0 24px; font-size: 0.92em; color: #718096; line-height: 1.7;" data-ke-size="size16">동전주 상장폐지 기준을 피하는 수단으로 가장 많이 쓰이는 것이 병합&middot;감자입니다. <a style="color: #2b6cb0;" href="https://moneyproducer.co.kr/2">30거래일 연속 종가가 1,000원 밑이면 관리종목으로 지정된다는 그 기준</a>을 숫자만 바꿔서 피해 가는 방법이기 때문입니다.</p>
<p style="margin: 0 0 24px; padding: 18px 20px; background: #f4f6f8; border-left: 4px solid #2b6cb0; border-radius: 4px; line-height: 1.75;" data-ke-size="size16"><b>핵심 요약</b> <b>병합</b>은 여러 주식을 하나로 합쳐 주가를 올리고, <b>감자</b>는 주식 수를 줄여 자본금을 낮춥니다.<br />둘 다 <b>보유 지분의 가치는 바뀌지 않습니다.</b> 숫자만 재배열될 뿐입니다.<br />동전주 관리종목으로 지정된 뒤에는 <span style="color: #c53030;">병합&middot;감자에 제약이 붙습니다.</span><br />지정 <b>전</b>에 미리 해둔 병합은 이 제약을 받지 않습니다.</p>
<h2 id="b1" style="margin: 44px 0 16px; padding-bottom: 10px; border-bottom: 2px solid #2d3748; font-size: 1.5em; scroll-margin-top: 70px;" data-ke-size="size26">1. 숫자만 바뀌고 가치는 그대로입니다</h2>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">10주를 갖고 있던 사람이 <b>병합</b> 소식을 들으면 반가워합니다. 10주가 1주가 되는 대신 그 1주의 가격이 10배가 되니까요. 500원이던 주식이 5,000원이 됩니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">그런데 갖고 있던 총 금액은 그대로입니다. 500원짜리 10주(5,000원어치)가 5,000원짜리 1주(역시 5,000원어치)로 바뀐 것뿐입니다. <b>파이 조각의 개수가 줄고 조각 하나의 크기가 커진 것이지, 파이 전체가 커진 게 아닙니다.</b></p>
<div style="overflow-x: auto; margin: 0 0 8px;">병합 전후, 보유 가치는 그대로병합 전10주 &times; 500원= 5,000원병합 후 (10:1)1주 &times; 5,000원= 5,000원</div>
<p style="margin: 0 0 22px; font-size: 0.85em; color: #718096;" data-ke-size="size16">그림: 병합은 조각 수를 줄이고 조각 크기를 키울 뿐, 전체 가치를 바꾸지 않습니다</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16"><b>감자</b>도 원리는 비슷하지만 방향이 다릅니다. 회사가 발행주식 수를 줄이면서 <b>자본금 자체를 축소</b>합니다. 재무제표상 누적된 결손금을 지우는 용도로 주로 쓰이고, 병합과 달리 주주에게 아무런 보상 없이 진행되는 <b>무상감자</b>가 흔합니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">병합 비율만큼 보유 주식 수도 줄어듭니다. 10:1 병합이면 100주가 10주가 되고, 대신 주당 가격이 10배로 조정돼 보유 총액은 동일합니다. 병합 후 1주 미만이 되는 잔여분(단주端株)은 현금으로 정산됩니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">이론상으로는 비율대로 즉시 조정되지만, 실제 시장에서는 병합 자체가 투자심리에 영향을 줘 이론가와 다르게 움직이는 경우가 있습니다. 특히 동전주 병합은 &ldquo;요건 회피용&rdquo;이라는 인식 때문에 병합 후 오히려 매도가 몰리는 사례도 있습니다.</p>

<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">동전주 요건 대응에는 <b>주식병합</b>이 주로 쓰입니다. 자본금을 안 건드리면서 주가 표시만 올릴 수 있기 때문입니다. 다만 재무구조가 나쁜 회사는 감자를 함께 진행해 결손금을 정리하고, 그 직후 병합으로 주가를 맞추는 경우도 흔합니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16"><b>무상감자는 모든 주주에게 동일 비율로 적용되므로 지분율 자체는 바뀌지 않습니다.</b> 다만 보유 주식 수와 자본금이 함께 줄어듭니다. 특정 주주만 감자 비율이 다르게 적용되는 <b>차등감자</b>는 지분율이 바뀌므로 별도로 확인해야 합니다. 감자 대가로 주주에게 현금이나 자산을 지급하는 <b>유상감자</b>와도 다른데, 동전주 대응 맥락에서는 대부분 무상감자입니다.</p>
<h2 id="b3" style="margin: 44px 0 16px; padding-bottom: 10px; border-bottom: 2px solid #2d3748; font-size: 1.5em; scroll-margin-top: 70px;" data-ke-size="size26">3. 그런데 왜 다들 이걸 하려고 하나</h2>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">가치가 안 바뀐다면 왜 회사들이 앞다퉈 병합을 하려는 걸까요. 이유는 <b>가치가 아니라 &lsquo;표시 가격&rsquo;이 요건을 결정하기 때문</b>입니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">동전주 상장폐지 요건은 &ldquo;종가 1,000원 미만&rdquo;이라는 <b>숫자</b>를 봅니다. 회사의 실제 가치나 시가총액이 아니라 표시된 주가 그 자체입니다. 500원짜리 주식을 10:1로 병합하면 산술적으로 5,000원이 되고, 그 순간 &ldquo;1,000원 미만&rdquo; 요건에서 벗어납니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16"><b>회사 실적이나 사업 전망은 병합 전후로 단 하나도 바뀌지 않습니다.</b> 오직 숫자를 표시하는 방식만 바뀝니다. 그래서 이 방법이 요건을 &ldquo;해결&rdquo;하는 것이 아니라 &ldquo;우회&rdquo;하는 것으로 불리는 것입니다.</p>
<p style="margin: 0 0 22px; padding: 18px 20px; background: #fff5f5; border-left: 4px solid #e53e3e; line-height: 1.85;" data-ke-size="size16">동전주 상장폐지 개정이 겨냥한 지점이 정확히 여기입니다. <a style="color: #2b6cb0;" href="https://moneyproducer.co.kr/2">필라 글</a>에서 다룬 것처럼, 2026년 1월 말부터 5월 중순까지 병합 공시가 <b>176건</b> 나왔습니다. 전년 동기 6건과 비교하면 약 30배입니다. 실제 사업이 30배 늘어난 게 아니라, <b>표시 가격 우회 수요가 그만큼 몰렸다</b>는 뜻입니다.</p>
<h2 id="b4" style="margin: 44px 0 16px; padding-bottom: 10px; border-bottom: 2px solid #2d3748; font-size: 1.5em; scroll-margin-top: 70px;" data-ke-size="size26">4. 관리종목 지정 후에는 막힙니다</h2>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">이번 개정에서 이 우회로에 제동이 걸렸습니다. 다만 <b>시점이 갈립니다.</b> 정확한 문구는 <b>금융위 원문</b> 그대로 이렇습니다.</p>
<blockquote style="margin:24px 0;padding:16px 18px;background:#fbfaf6;border:1px solid #e6e2d6;line-height:1.85;font-size:.96em;"><b>「(1)최근 1년 이내에 주식병합이나 감자를 한 경우, 동전주 관리종목 지정 이후 90거래일 동안 추가적인 주식병합&middot;감자를 금지*하고, (2)동전주 관리종목 지정 이후 90거래일 동안 10:1을 초과하는 주식병합&middot;감자도 금지*한다.」</b><br><b>「* (1), (2)의 주식병합 및 감자를 즉시 상장폐지 사유로 규정하여 사실상 금지」</b></blockquote>
<p style="margin:0 0 19px;line-height:1.85;">미리 병합해 둔 회사는 그 이력 때문에 정작 지정된 뒤에 병합 카드를 못 씁니다. 다만 「최근 1년」의 기산점은 조문을 못 열어 확인 못 했습니다.</p>
<p style="margin:0 0 19px;line-height:1.85;">그리고 「감자 10:1 하면 3,000원」은 (2)에 안 걸립니다. 금지된 것은 「10:1을 초과하는」 쪽이라서요. 그 계산을 막는 것은 (1)이고, 그것도 최근 1년 안에 병합&middot;감자 이력이 있을 때만입니다.</p>
