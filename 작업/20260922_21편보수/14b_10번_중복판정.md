# 14b — `/10` × `/5` 중복 판정 (판정만, 집행 없음)

**`/10`은 이 호출에서 본문을 한 글자도 고치지 않았다.** 아래는 판정뿐이다. 처분 집행은 사장이 정한다.

## 표

| 항목 | 값 | 센 명령어 |
|---|---|---|
| 겹치는 대목 | `/10` 말미 &ldquo;관리종목이 아닌데 정지되기도 합니다&rdquo; 단락 — 관리종목 지정≠거래정지 구분을 한 줄로 되짚는 대목 | 육안 대조(아래 §1) |
| 겹치는 분량 | **117자(공백제외)** — `/10` 전체 5,150자(공백제외) 중 **2.3%** | `python3` 로 해당 단락만 잘라 `len(re.sub(r'\s+','',text))` (아래 §2 재현 명령) |
| 글자까지 같은 문자열 | **없음.** 최장 공통 부분문자열이 「이 글은 동전주 상장폐지 기준 총정리의 하위 글입니다」(31자, §3 공통 처분 대상 그 자체) 뿐, 실제 설명 문장은 겹치지 않음 | `difflib`/슬라이딩 윈도 대조 (아래 §3) |
| 제자리 판정 | **`/5`.** `/10`은 이미 이 대목에 `href="https://moneyproducer.co.kr/5"` 링크(앵커 &ldquo;관리종목 지정되면 어떻게 되나&rdquo;)를 걸고, 원문 상세는 `/5`로 떠넘긴 뒤 한 줄만 요약한다 | `grep -c 'href="https://moneyproducer.co.kr/5"' 폐기/20260922_묶음4/body10.html` → 1 |

## 판정

**중복이 아니다.** 이번 호출이 §3·꼬리에서 요구한 &ldquo;본문 맥락 안의 문맥 링크&rdquo;를 `/10`이 이미 하고 있는 사례다 &mdash; 117자짜리 다리 문장 하나로 `/5`에 위임하고 본문을 늘리지 않았다. 21편이 한 틀에서 찍힌 것처럼 보이는 문제(ⓒ)와는 반대 방향이다.

## 처분 (적되 집행하지 않음)

**필수 처분 없음.** 다만 더 다듬고 싶다면 두 갈래가 있다 — ① 그대로 둔다(다리 문장으로 이미 기능함) ② 117자를 &ldquo;관리종목 지정되면 어떻게 되나에서 다룬 것처럼, 관리종목과 거래정지는 별개입니다.&rdquo; 한 문장(약 40자)으로 더 줄인다. 어느 쪽이든 `/5`의 §1 내용을 `/10`으로 옮겨오거나 반대로 옮기는 처분은 **근거 없음** &mdash; 두 편의 앵글이 다르다(`/5`=계좌에서 무엇이 바뀌나, `/10`=공시 문구 1,124건 분류).

---

## §1 — 대조 원문 (육안)

`/5` §1: &ldquo;관리종목 지정 소식을 들으면… 그렇지 않습니다. [표: 관리종목 지정=매매 계속 가능 / 매매거래정지=사고팔 수 없음] 둘은 별개의 조치입니다…&rdquo;

`/10` 말미: &ldquo;두 단어는 자주 섞이지만 별개입니다. 관리종목 지정되면 어떻게 되나(→`/5`)에서 다뤘듯 관리종목 지정은 &lsquo;투자에 주의가 필요하다&rsquo;는 꼬리표라 매매는 대부분 계속됩니다. 거래정지는 아예 멈춰 못 팝니다. 관리종목이 아닌데 갑자기 정지되기도 합니다. 첫 칸 705건이 그렇습니다.&rdquo;

## §2 — 겹치는 분량 재현 명령

```
python3 -c "
import re
h = open('폐기/20260922_묶음4/body10.html', encoding='utf-8').read()
i = h.find('두 단어는 자주 섞이지만')
j = h.find('참고로 VI')
seg = re.sub(r'<[^>]+>','', h[i:j])
print(len(re.sub(r'\s+','', seg)))
"
```
결과: **117**

## §3 — 최장 공통 부분문자열 재현 명령

```
python3 -c "
a=open('폐기/20260922_묶음4/body5.txt').read()
b=open('폐기/20260922_묶음4/body10.txt').read()
def lcs(a,b,minlen=10):
    i=0; out=[]
    while i<len(a):
        j=i+minlen; last=None
        while j<=len(a) and a[i:j] in b:
            last=j; j+=1
        if last: out.append(a[i:last]); i=last
        else: i+=1
    return out
for s in lcs(a,b,10): print(len(s), repr(s))
"
```
가장 긴 것이 &ldquo;이 글은 동전주 상장폐지 기준 총정리의 하위 글입니다.&rdquo;(31자, §3 공통 처분에서 어차피 전부 제거 대상) 뿐이고, 그다음은 &ldquo;최종 수정일: 2026. &rdquo;(14자, 날짜 서식) 같은 템플릿 조각이다. 설명 문장 단위의 실질 중복은 없음.
