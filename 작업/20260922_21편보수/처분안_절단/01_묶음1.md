### ㉠ `/2` ← `/9` — 동전주·시가총액 형식요건

| | |
|---|---|
| **남길 URL** | **`/2`** (노출 1,296 · 클릭 3 · 게재순위 7.51 — 21편 중 노출 2위) |
| **사라질 URL** | **`/9`** (노출 13 · 클릭 0) |
| **301** | **필요하다.** `/9` → `/2`. 노출 13이라 손실은 작지만, 401 아닌 404로 두면 죽은 링크가 남는다 |

### ㉡ `/13` ← `/14` + `/15` — 실질심사

| | |
|---|---|
| **남길 URL(1안 · 내가 권한다)** | **`/13`** — 통합 뒤 글의 주제가 「실질심사」이고, `/13` 제목이 그 주제다. §5~§7(심사 단계·개선기간·이의신청)이 통합 글의 뒷부분을 그대로 이룬다 |
| **남길 URL(2안)** | **`/14`** — 노출로는 `/14`(80) > `/15`(29) > `/13`(17)이고, 클릭도 `/14` 2 · `/15` 2 · **`/13` 0**이다. **숫자만 보면 `/13`이 셋 중 가장 안 팔린 글이다** |
| **사라질 URL** | 1안이면 `/14`·`/15` (노출 합 109) · 2안이면 `/13`·`/15` (노출 합 46) |
| **301** | **필요하다.** 어느 안이든 두 URL이 사라진다 |
| **근거(실측)** | `/13` §3이 *"2026년에 새로 추가된 반기 기준은 기업심사위원회 심의를 거치는 실질심사 방식으로 도입됐습니다"* 로 **`/14`의 결론을 이미 말한다.** `/13` §4 표가 *"완전자본잠식(반기 기준, 2026년 신설) — 심사위원회 심의 / 공시위반(벌점 10점 이상) — 심사위원회 심의"* 로 **`/14`·`/15` 둘을 한 칸씩 차지시켜 놓았다.** 본문 문자열 겹침도 `/13`↔`/14` **4.5%로 21편 전 쌍 중 1위** |
| **덧** | `/14`·`/15`는 **21편 중 본문 표가 0행인 넷에 둘 다 들어간다.** 통합하면 `/13`의 §4 표가 셋의 공통 표가 된다 |

> **어느 안으로 갈지는 사장이 정한다.** 나는 두 안의 실측을 다 적었고, 고르지 않는다.
