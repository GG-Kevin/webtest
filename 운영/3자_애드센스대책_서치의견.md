# 서치 의견 — 애드센스 재거절 대책 6관문 (2026-10-04, 전략실 요청)

범위: 전략실 요청문에 적힌 관문 6개와 서치 쪽 실측만 근거다. 전략실 초안 파일과 9/26 검토 문서는 이 세션에 붙어 있지 않아 읽지 않았다.

1. **동의: 관문을 고치기 대신 기준으로 둔다.** 옛 글은 H-193대로 고치지 않고, 새 글만 쌓으며 재신청은 관문 통과 뒤에 한다.
2. **같은 꼴 지적은 사실이다(실측).** 대기 12편 중 h2 7~9개(전부), 표 4개 9편(3개 2편, 5개 1편), 그림 2장 12편 전부, 제목 앞 키워드 + 숫자 꼴. 원인은 변환 규칙 숫자(표 2~4, 그림 1~3)를 작가 전원이 같은 값으로 읽은 것이다.
3. **관문 3(같은 구성 4편 이하): 다음 글부터 넣을 수 있다.** 작가용 설계도에 「이 편의 h2 수·표 수·그림 수를 직전 10편과 다르게」를 한 줄로 넣고, 설계자가 직전 10편 표(h2·표·그림 수)를 보고 정한다. 이미 쓴 12편은 고치지 않는다(H-193). 이 때문에 새 틀 30편 중 앞 12편은 같은 꼴로 세어질 수 있다.
4. **관문 5(바이라인 + 수정 이력 칸): 서치 단독으로 안 된다.** 저자 박스는 `발행/저자소개_원고.md`(본사 도구 소관)이고, 「수정 이력」 칸은 본문 모양이 바뀌므로 변환기와 저자 박스를 본사가 고쳐야 한다. 다음 글부터 넣으려면 본사가 저자소개 원고와 변환기 계약을 바꿔야 하고, 이미 대기에 올린 12편에도 칸이 붙을지는 본사 결정이다.
5. **관문 4(글마다 고유 자료 1개): 이미 하고 있다.** 글마다 직접 계산표와 「더한 것 ③」(원문에서 다시 뽑은 사실)을 심사에서 확인한다. 이를 「고유 자료」로 인정할지 전략실 정의를 알려 달라.
6. **관문 1·2(30편 라이브, 2주 매일 발행): 서치가 아니라 올리는 쪽 일이다.** 서치는 하루 4편을 대기에 쌓는다. 지금 라이브 22편(옛 틀) + 대기 12편이다. 매일 발행은 발행 담당이 정한다.
7. **관문 6(노출 0·고유 재료 0 옛 글 비공개 후보): 서치가 뽑을 수 있다.** 노출 자료(서치콘솔 권한은 요청하지 않는 규칙 H-189 ⑦)가 없으면 방문기록·카운터로 대신 뽑는다. 비공개 처리는 회장 결정대로 서치가 수정하지 않고 본사가 한다.
8. **우려:** 관문이 규칙 더하기로 번지면 같은 글이 나온다는 회장 말(H-194)과 부딪힌다. 관문 3은 규칙이 아니라 직전 10편과 다르게 쓰라는 한 줄로만 둔다.
