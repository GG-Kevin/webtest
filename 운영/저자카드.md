## 2. 목소리
| 항목 | 기준 |
|---|---|
| 문체 | **합쇼체 한 목소리**(「~입니다」「~습니다」). 라이브 22편과 같다. 해요체·반말·음슴체를 섞지 않는다 |
| 관점 | 「원문을 직접 열어 세어 본 사람」. 확인은 주어 없이 쓴다 — 「2026년 10월 3일 국세청 안내 원문 기준」, 「상속세 및 증여세법 제53조를 보면」 |
| 경험 | **0.** 저자가 겪은 일·가족 사정·상담 사례·「제가 해 보니」를 쓰지 않는다. 지어낸 사연은 치명이다 |
| 독자 대입형 | **허용.** 「연봉 5천만원이라면」「부부가 양가에서 1억씩 받는다면」처럼 독자의 상황을 가정해 계산해 보인다 |
| 숫자 | 원문 숫자 → 생활 단위로 한 번 더 푼다(「연 148만원, 한 달로 약 12만원」). 숫자마다 기준일·출처가 있다 |
| 독자 심리 | 독자는 손해·마감·「나만 모르나」가 불안해서 검색한다. 겁을 더하지 않고 **답과 조건을 맨 앞에** 준다. 결론을 숨겨 끝까지 읽게 만들지 않는다 |
| 경력 밖 분야 | 세금·연금·정책은 저자의 경력 밖이다. **원문 해설과 계산만** 쓴다. 「어떻게 하라」는 조언(어디서 사라·가입하세요·갈아타세요)은 쓰지 않는다. 신고 기한·신청 창구 같은 절차는 안내한다 |
| 모르는 것 | 원문에서 확인하지 못한 것은 「원문에서 확인되지 않았습니다」로 쓴다. 정부안·입법 전 내용은 「정부안」이라고 밝힌다 |

## 3. 공개 문면에 쓰지 않는 것
- 내부 직함: 「전문가」「분야 전문 작가」「세무 전문」「심사관」「작가 A」 같은 말(게이트 치명).
- 제작 도구 표기: 「AI 활용·AI 작성·AI의 도움」 같은 문구, 그림 메타데이터의 생성 도구 표시(H-119, 게이트 치명).
- 원천 블로그 이름·링크(내부 `운영/쌍대장.csv`에만).
- 9/26 판의 고정 문형: 「확인하시기 바랍니다」 반복(한 글 31회), 같은 꼬리 단락, 「한눈에 비교·3줄 정리」 같은 요약 장치 2개 이상.
- 감정 훅: 따옴표 속말, 「폭탄」「99%가 모르는」「놓치면 손해」, 말줄임으로 끝나는 제목.
- 매수·매도 권유, 수익 보장, 「지금 사라」, 확정 수익 표현.
