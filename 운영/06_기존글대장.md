## 한 줄 요약

**22편 전부 동일 구조다.**

```
핵심요약 박스 → 목차 → 번호 붙은 절(6~8개) → 자주 묻는 질문 → 안내 문구
```

HTML 인라인 스타일까지 동일. 썸네일도 한 틀로 22장. 이것이 거절 사유의 직접 원인이다.

**따라서 당분간 위 구조는 전면 금지한다.** 겹침 여부를 따질 필요도 없다.

## 이미 소진된 것 — 재사용 금지 대상

**구조**
- 핵심요약 박스로 시작하는 모든 형태
- 클릭 가능한 목차 블록
- 번호 붙은 절 나열
- 말미 "자주 묻는 질문"
- 말미 회색 "안내" 박스

**도입**
- 요약 박스 직행
- "~하면 대부분 …부터 떠올립니다" 형태의 후킹 문단

**제목**
- "A — B" 대시 이분 구조 (22편 중 다수)
- "~ 총정리", "~ 완벽 정리"

**썸네일**
- 남색 배경 + 노란 배지 + 흰 2줄 제목 + 노란 키워드 (22장 전부)

## 「설계」가 써야 할 것

위 목록에 없는 형태를 찾는다. 예시이며 지정이 아니다. 여기 적힌 것을 그대로 쓰라는 뜻이 아니다.

- 한 사람의 사례를 따라가는 서사
- 질문과 답만으로 구성
- 시간순 재구성
- 직접 해본 과정의 기록
- 비교표 하나가 본문인 형태
- 체크리스트 중심
- 대화체
- 짧은 글 (1,500자 이하)
