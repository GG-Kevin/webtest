# 서치 품질 기준 (H-163 · 2026-10-02 · 회장 지시)

> 회장 원문(본사 경유): 「서치도 글 쓰면서 퀄리티 점수를 기준을 만들라고 해. 치명적인 오류가 아니면 85점이나 90점이면 그냥 넘어가라고 해」

검수(sonnet) 1회가 치명과 점수를 같이 낸다. 산출 첫 줄: `치명: 통과|실패 · 점수: N`

## 1층 — 치명 목록 (하나라도 걸리면 점수와 무관하게 고친다)
1. 매수·매도 권유·수익 보장·「지금 사라」 류
2. 숫자마다 출처와 기준일이 없음
3. 계산 재현 불가(글에 기간·방법 한 줄 없음, 표가 스크립트 출력과 불일치)
4. 지어낸 경험담
5. 「AI 활용·AI 작성」 문구
6. 다른 블로그 문장 20자 넘게 옮김
7. 애드센스 정책 위반(과장·클릭 유도)
8. 제목·요약·결론 문장이 본문 데이터와 맞지 않음
9. 해석이 숫자를 거꾸로 말함

## 처리 (재채점 없음)
| 결과 | 처리 |
|---|---|
| 치명 있음 | 반드시 고친다(수정 1회), 점수와 무관 |
| 치명 0 · **85점 이상** | **그대로 통과. 더 고치지 않는다** |
| 치명 0 · 70~84점 | 지목된 곳만 수정 1회 뒤 통과 |
| 70점 미만 | 주제 교체 |

- 7편 첫 글부터 적용한다. 점수는 감점 항목을 적어서 낸다(근거 없는 점수 금지).
- 검수가 못 연 파일·못 재계산한 숫자는 「못 열었다」로 적고, 그 항목은 감점하지 않고 보고에 남긴다.
