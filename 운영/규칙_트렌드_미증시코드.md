# 규칙 — 어드바이저 트렌드 · 미증시 코드 (본사 H-202·H-203, 회장 10/4 직접 지시를 본사가 전달)

회장 원문(본사 전달): 「모두 트랜드를 파악하고 첫 글을 개시해」 · 「미증시 얘기면 미증시 코드를 종목명과 반드시 같이 써 줘」. CLAUDE.md는 고치지 않고 이 파일에 둔다. 설계자·작가용 설계도에 아래 2번을 그대로 넣는다.

## 1. 정찰에 더하는 신호 — 네이버 크리에이터 어드바이저 「비즈니스·경제」 인기유입검색어
- 매일 08:00쯤 노트가 `GG-Kevin/claude_naver` 브랜치 `claude/delxom-life`의 `작업/<날짜>/어드바이저_트렌드.md`에 둔다. 정찰 때 이 파일을 읽어 「지금 가장 많이 찾는 경제 검색어」를 질문 후보 순서에 반영한다(합의·달력·자동완성과 같은 급의 신호).
- 이 세션은 해당 레포에 붙어 있지 않아(2026-10-04 확인) 아직 읽지 못했다. 읽는 길은 본사가 연다(본사 세션 보고에 한 줄). 길이 열리기 전에는 기존 3신호로 정찰하고, 막혔다고 멈추지 않는다.
- 트렌드 검색어가 반려대장·주제대장에 걸리면 버린다(gate_topic이 우선).

## 2. 미국 주식·ETF 표기 — 이름과 코드를 반드시 함께
- 적용: 새 글의 제목·본문·표·그림(alt 포함) 전부. 예: 엔비디아(NVDA), 나스닥100 ETF(QQQ), S&P500 ETF(SPY).
- 처음 나올 때 「이름(코드)」, 이후에도 표·그림 라벨에서는 코드를 같이 쓴다. 코드는 거래소 공시·운용사 원문에서 확인한 것만 쓴다.
- 이미 쓴 글·대기 10편은 고치지 않는다(H-193). 대기 10편에는 미국 주식·ETF가 없다.
- 단, 미국 ETF·해외 ETF·나스닥·S&P 주제는 gate_topic이 막는 구간이 있다. 막히면 우회하지 않고 본사 승인을 받는다.
