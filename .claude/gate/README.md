- 본사 원본: claude_ebook `본사/게이트/서치/`. 서치 사본: 서치 레포 `.claude/gate/`(본사 실장이 원본을 복사한다. 서치는 실행만 한다).
- 근거: 개편안 v3.1 · v3 · 본사 안 1-2 ③·3-2·3-3 · v2 2-3(반려·중복 게이트 명세)·2-5 분기 표·부록 C(모의) · 초안 2-3(금지 낱말 표·동의어).
- 같은 폴더의 다른 게이트(gate_frame 틀 상한·쌍둥이·지문, overlap21 21자 겹침)는 각 스크립트 머리말과 `README_frame.md`를 본다. 이 문서는 gate_topic만 다룬다.

## 1. 사용법
| 언제 | 누가 | 명령(서치 레포 루트에서) |
|---|---|---|
| 정찰 뒤 질문은행 | 정찰 스크립트 | `python3 .claude/gate/gate_topic.py 운영/질문은행.csv` |
| 묶음 설계·편성표 커밋 전 | 설계자·사장 | `python3 .claude/gate/gate_topic.py 작업/설계/<묶음>.md` |
| 최종 제목 | 사장 | `printf '<최종 제목>\t<사건키>\n' \| python3 .claude/gate/gate_topic.py - --mode title --exclude-self <원장 줄>` |
| 05:20 승인 | 본사 | `python3 /home/user/claude_ebook/본사/게이트/서치/gate_topic.py <편성표> --repo <서치 레포(최신 커밋)>` |

- 입력은 세 가지다.
  - 줄 파일: 줄마다 `문구<TAB>사건키`. 사건키가 없으면 `-`. `#` 줄과 빈 줄은 건너뛴다. 셋째 칸부터는 읽지 않는다. **문구가 빈 줄은 오류(종료 2)**.
  - 마크다운 표(.md): 머리에 주제·질문·질문 원문·검색어·가제·제목·최종제목·디스커버 제목·사건키(·묶음·편) 칸 중 있는 것. 칸 이름 끝의 `(…)`는 떼고 읽는다(「가제(안)」 = 가제, 「질문(구글 원문)」 = 질문). 「제목 1안」「제목 후보2」는 모두 제목으로 읽는다. 각도·차별점·이유·메모·자기검토·h2 질문 칸은 읽지 않는다.
  - CSV(.csv): 같은 칸 이름(질문은행.csv·원장.csv 모양).
- **조용히 건너뛰지 않는다(fail-closed)**: 머리에 질문·제목·가제·검색어·주제 글자가 있는데 정해진 칸 이름이 아니면 종료 2로 그 이름을 알린다. 문구 칸이 빈 표 행(다른 칸은 있음)도 종료 2. 후보가 0개면 종료 2(「후보 없음」). 출력 합계 줄에 「읽은 표 n개 · 건너뛴 표 m개」를 찍는다.
- `--mode title`: 최종제목·제목·디스커버제목 칸만 본다(없으면 가제). 읽을 칸이 하나도 없으면 종료 2.
- `--repo`: 서치 레포 루트. **본사 원본에서는 꼭 준다**(없으면 종료 2). 서치 사본(`<레포>/.claude/gate/`)에서만 `../../`를 기본값으로 쓴다. 그 자리에 `운영/`이 없으면 종료 2.
- `--exclude-self N`: 진행분 대조에서 뺄 원장.csv 줄 번호(자기 줄). 표 입력에 묶음·편 칸이 있으면 같은 묶음·편의 원장 줄은 저절로 뺀다.
- `--json`(스크립트용) · `--only-fail`(실패 줄만).
- 종료코드: 0 = 전부 통과 · 1 = 실패 있음 · 2 = 사용·데이터 오류(후보 없음·빈 문구·읽을 수 없는 표 머리·데이터 칸 수·빈 칸·정규식 오류·빈 문구에 맞는 정규식·사건키 겹침·주제대장 사건키 미등록·`--repo`).

출력 한 줄이 후보 하나다(아래는 서치 원장 22줄 + 회장 예외 줄을 둔 시험 레포에서 실제로 찍힌 줄).
```
실패: 사건 한글날휴장 ← 이미 다룬 글 /27(사건키 줄11) ; 휴장 ← W-19(반려대장 줄41) [일정형 예외 안 됨: 문구에서 찾은 안 다룬 달력 사건 없음 · 이미 다룬 사건] ; 휴장 ← 주제대장 /22(줄27) ; 휴장 ← 주제대장 /27(줄31) ; 한글날 ← 주제대장 /27(줄31) ; 진행분 사건키 한글날휴장 ← 원장 줄21(기존//27 라이브) | 입력 줄1: 10월 9일 한글날 증시 휴장
통과(일정형 예외): 근로장려금 ← 주제대장 /8(줄13) ; 사건 근로장려금지급12월 ← 찾은 키 · 다룬 글 없음 ; 날짜 하반기·12월 ← 날짜 토큰 | 입력 줄2: 근로장려금 하반기분 12월 지급일

실패: VI ← 주제대장 /11(줄16) [일정형 예외 안 됨: 문구에서 찾은 안 다룬 달력 사건 없음 · 낸 키 「FOMC10월」의 정규식(사건키 줄39)이 문구와 맞지 않음] ; 진행분 검색어 「VI 발동」 ← 원장 줄8(기존//11 라이브) | 입력 줄4: VI 발동 조건 2026

# 합계 6 · 통과 2(일정형 예외 1 · 회장 예외 1) · 실패 4 · 모드 topic · 입력 줄 파일
# 대조: 반려대장.tsv 줄8~55 (제목 15 · 낱말 30 · 정규식 3) · 주제대장.tsv 줄9~33 (25편) · 사건키 48개(다룬 사건 27) · 동의어 34줄 · 원장 22줄 진행분(기존 22) / 전체 22 · 반려_추가 0줄, 삭제 흔적 0 · repo …
# sha256(앞 16자): gate_topic.py … · 반려대장.tsv … · 주제대장.tsv … · 동의어.tsv … · 사건키.tsv …
```
- `←` 오른쪽이 근거다: `R-nn`·`W-nn`(반려대장 줄) · `주제대장 /N(줄)` · `이미 다룬 글 /N(사건키 줄)` · `원장 줄n` · `반려_추가 줄n` · `B7-n`(본사 결정 정규식) · `git <커밋>`(삭제 흔적).
- 통과 줄의 꼬리표: `(일정형 예외)` = 걸린 낱말을 달력 사건이 연 것, `(회장 예외 원문 n줄)` = 회장 1회 예외. 본사 05:20 승인에서 이 두 꼬리표 줄은 눈으로 본다. 합계 줄의 「일정형 예외 n · 회장 예외 n」은 **통과한 줄만** 센다.
- **대조 줄 번호 = 그 파일의 실제 줄 번호**(1부터, `#` 줄·빈 줄 포함). 맨 아래 `# 대조` 줄을 본사 승인 파일에 옮긴다. `# sha256` 줄로 서치 사본과 본사 원본이 같은지 본다.
  - 주의: 같은 폴더 `gate_frame.py`(`read_tsv`)는 `#` 줄·빈 줄을 뺀 순번(머리 = 1)으로 센다. 두 게이트의 줄 번호가 다르다 — gate_frame 담당이 「실제 파일 줄」로 맞출 때까지 승인 파일에는 gate_topic의 `# 대조` 줄만 옮긴다.
- 표준 오류의 「주의」 줄: 원장 없음·git 아님·낸 사건키 미등록. 판정은 그대로 한다.

## 2. 판정 순서(한 후보 안)
| 순서 | 무엇 | 걸리면 | 예외 |
|---|---|---|---|
| ① 반려 | 반려대장 「제목」 줄(후보에 통째로 들어 있음) · 「낱말」 중 예외 「없음」 · 「정규식」 줄 · 본사 결정 B7 정규식 | 실패 | 회장 1회 예외만 |
| ② 사건키 | 사건키.tsv 정규식이 문구에서 **찾은 키** + 후보가 **낸 키**. 그 사건을 다룬 우리 글(사건키.tsv 「다루는 글」 또는 주제대장 「다루는사건키」)이 있으면 | 실패 | 회장 1회 예외만 |
| ③ 주제대장·회장 지적 중복 | 주제대장 핵심어 · 반려대장 낱말 중 예외 「일정형」(IRP·달러·휴장·개장 시간) | 실패 | 일정형 예외(아래 네 조건) · 회장 1회 예외 |
| ④ 진행분 | 운영/원장.csv 상태 승인·집필·완성·대기·라이브 줄의 검색어(후보에 통째로 들어 있음)·가제·최종제목(같거나 한쪽이 다른 쪽을 품음)·사건키(같음) | 실패 | 자기 줄(`--exclude-self`, 같은 묶음·편)만 뺀다. **묶음 「기존」 줄**(개편 전 22편 — 또는 편·라이브URL이 주제대장 /N)은 ③과 같은 층: 회장 1회 예외로만 넘고 일정형 예외로는 못 넘는다. **개편 뒤 진행분은 회장 예외로도 못 넘는다**(같은 주제 두 번째 글 = 「1회」) |
| ⑤ 반려_추가 | 운영/반려_추가.txt 줄(첫 칸이 낱말) | 실패 | 회장 1회 예외만 |
| ⑤' 삭제 흔적 | git 기록(커밋 + 작업본)에서 반려_추가.txt의 줄(`#` 줄 아님)이 지워졌고 지금 파일에 없으면 | **모든 후보 실패** | 없음 |
| ⑥ 회장 1회 예외 | 운영/회장지시_원문.md의 `1회 예외: <문구>`와 **정확히 같은 칸 하나**만 ①②③④(기존)⑤를 넘는다. 같은 행의 나머지 칸은 평소대로 판정해 하나라도 실패하면 그 행은 실패. 예외 줄 하나는 **한 실행에서 후보 하나만** 통과시킨다(두 번째부터 「이미 입력 줄n에 썼다(1회)」로 실패) | — | ④ 개편 뒤 진행분·⑤' 삭제 흔적은 못 넘는다 |

**일정형 예외 — 네 조건을 모두 채워야 통과한다**(하나라도 빠지면 실패 줄에 `[일정형 예외 안 됨: …]`)
1. **찾은 키**: 사건키.tsv 정규식이 후보 문구에서 직접 찾은, 아직 안 다룬 사건(「다루는 글」 `-`)이 있다. 후보가 **낸 키로는 열리지 않는다** — `new`·`신규` 같은 이름 없는 키, 사건키.tsv에 없는 키(「본사가 등록한 뒤」), 등록됐지만 정규식이 문구와 안 맞는 키(「VI 발동 조건 2026<TAB>FOMC10월」). 낸 키는 실패를 더할 수만 있다(②·④ 대조).
2. **자리**: 걸린 낱말(③)이 모두 그 사건 정규식이 맞은 자리 안에 있다. 「원달러 환율 10월 FOMC」의 환율·달러는 FOMC10월 자리(「10월fomc」) 밖이라 실패한다. 그래서 안 다룬 사건의 정규식은 그 사건이 가질 낱말까지 덮게 쓴다(예: 추수감사절 … 휴장, 수능 … 개장 시간·휴장).
3. **다룬 사건 없음**: 찾은 키·낸 키 어느 것도 이미 다룬 사건이 아니다.
4. **날짜 토큰**(정규화한 문구에서):

| 날짜로 보는 것 | 날짜로 보지 않는 것 |
|---|---|
| 연도 2024~2029 | 「2000만원」「2026억」「2030세대」처럼 금액·인원·세대가 붙은 수, 그 밖의 연도 |
| N월(1~12) | 「13월의 월급」 |
| 연말 | 연말정산 |
| 1~4분기 · 이번·다음·지난·올해·내년 분기 · 분기 말·초 | 손익분기(점) · 분기배당 |
| 상반기 · 하반기 | 날짜 없이 붙은 「N일」(「3일 단일가매매」「1일 한도」) |

- 사건키를 「-」로 내도 게이트가 문구에서 사건을 찾는다(예: 「2026 대주주 양도세 기준 12월 마지막 거래일」 → 대주주기준일12월 → /28 실패).
- 정규화: NFKC → 소문자 → 동의어.tsv(긴 다른말부터) → 공백·기호(`· - & /`와 비슷한 점들) 제거 뒤 대조. 영문으로 시작하거나 끝나는 낱말(VI·SPY·QQQ·IRP·ISA·S&P 등)은 공백을 지우기 전 문구에서 앞뒤 글자가 영문이 아닐 때만 맞춘다(VIG 안의 VI, ISAAC 안의 ISA, SPYD 안의 SPY는 통과. 「QQQ SPY」는 둘 다 잡힌다).

## 8. 한계(남은 문제)
- 일정형 예외의 「자리」 조건은 사건 정규식이 맞은 글자 범위로 본다. 정규식의 `.*`가 길게 덮으면(「FOMC 금리 결정 환율 영향 10월」) 그 안의 낱말은 열린다. 그래서 통과 줄에 `(일정형 예외)`와 걸린 낱말을 모두 찍고, 본사 05:20 승인에서 이 줄을 눈으로 본다.
- 새 달력 사건은 본사가 사건키.tsv에 줄을 더한 뒤에야 일정형 예외를 연다(서치 calendar_build가 미등록 사건을 본사에 올린다).
- 같은 입력 파일 안의 후보끼리는 비교하지 않는다(쌍둥이는 gate_frame 몫).
- 묶음 안 하위 글의 검색어가 허브 글 검색어를 통째로 품으면 진행분으로 실패한다. 하위 질문은 다른 검색어로 쓴다.
- 사건키 정규식은 본사가 22편 본문을 읽고 쓴 것이다. 새 표현이 빠질 수 있다 → 시험 세트에 새 실패 예를 더하고 정규식을 넓힌다.
- 다룬 사건 정규식은 2026년 사건 기준이다(예: 「2027 개천절 증시 휴장」도 지금은 /27로 실패). 해가 바뀌면 본사가 다음 해 키를 더하고 옛 정규식에 해 조건을 건다.
- 회장 1회 예외는 칸 문구가 정확히 같아야 한다. 주제 단계(검색어)와 최종 제목 단계 문구가 다르면 서치가 원문에 두 문구를 각각 `1회 예외:` 줄로 적는다(줄 하나가 칸 하나를 연다).
- 표 머리 규칙이 엄격하다: 후보가 아닌 표에 질문·제목·가제·검색어·주제 글자가 든 칸 이름을 쓰면 종료 2다. 이름을 바꾸거나(예: 「참고」), 읽지 않는 이름(각도·차별점·이유·메모·비고·자기검토·h2 질문·근거)을 쓴다.
