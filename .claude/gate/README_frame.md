## 2. 판정
### 2-1. gate_frame — 편성표·설계(마크다운 표)
칸은 이름으로 찾는다: 검색어(질문) · 가제(제목) · 골격 · 묶음 · 편 · 게시일 · 사건키 · 유형(상시/일정형) · h2 · 원천.

| 판정 | 검사 | 근거 |
|---|---|---|
| 실패 | 검색어·가제 칸이 있는 표가 없음(틀 검사를 할 수 없으면 막는다) | 계약 「마크다운 표」 |
| 실패 | 골격 칸 없음 · 골격 이름이 4종(날짜형·계산형·비교형·절차형) 밖 | 본사 안 1-4 |
| 실패 | 묶음 안 같은 골격 | 본사 안 2-1 설계자 「묶음 안 같은 골격 0」 |
| 실패 | 하루(게시일) 같은 골격 3편 이상 | 맡은 일 명세(하루 2편 이하) |
| 실패 | 쌍둥이 글: 정규화한 검색어가 같음 · 핵심 명사 자카드 0.6 이상(검색어끼리, 제목끼리) | 본사 안 3-1, v3.1 반복 금지 |
| 실패 | 번호만 다른 같은 제목(「…2」「(2)」「2편」「Part 2」「①」) · 숫자만 바꾼 같은 제목 · 같은 제목 | v3.1 반복 금지 |
| 실패 | h2 칸이 번호형(50% 이상) · h2 순서가 라이브 글·다른 줄과 같음(숫자·지명만 다름) | v2 B2, v3.1 「자동 페이지」 |
| 실패 | 서브도메인 링크(moneyproducer.co.kr 의 www 밖 하위 도메인) | v3.1 반복 금지 |
| 경고 | 주 일정형 11편 초과 · 하루 일정형 2편 초과 · 하루 4편인데 네이버 합의 2편 미만 · 한 원천 하루 2편 초과 | v3.1 편성 비율, 본사 안 3-1 |
| 기록 | 게시일 칸이 없으면 하루 골격 상한은 세지 않음 | — |

- 쌍둥이 비교 범위: 같은 입력의 다른 줄 + 주제대장 전체(핵심어는 쉼표로 나눈 문구마다 따로 맞대고, 제목은 제목끼리) + 원장 진행분(승인·집필·완성·대기·라이브·보류. 후보·취소는 뺀다).
- 정규화: NFKC·소문자 → 조사 떼기(「한도」「제도」「나이」처럼 조사처럼 끝나는 낱말은 지킴) → 숫자·연령·연도·지역·넓은 말(방법·정리·기준·계산·비교 …) 빼기 → 붙여 쓴 복합어는 입력·대장에 있는 낱말로 쪼갬(「결혼증여세」=「결혼」「증여세」).
- 다른 사건 예외: 두 쪽 모두 사건키가 있고 서로 겹치지 않으면(「공모주11월」·「공모주12월」) 쌍둥이·숫자만 바꾼 제목으로 보지 않는다(v2 B1 「날짜가 다르면 다른 사건」). 사건키가 없으면(「-」) 예외가 없다.
- 같은 글 빼기: 같은 묶음+편, 또는 검색어와 가제가 둘 다 같은 줄은 한 글이다(편성표와 설계를 같이 넣어도 두 번 세지 않음). 원장 줄도 같은 규칙으로 자기 줄을 뺀다.

### 2-3. overlap21 — 21자 같은 글자열
- 뽑기: `.html` 은 본문 블록(문단)마다, `.md` 는 줄마다, `.txt` 는 줄마다 그대로.
- 제외(대상·상대 모두): 면책 문장 · 「안내」 상자(라이브 22편 끝 면책 + 최종 수정일) · 바이라인(저자 칸) · 수정 이력·최종 수정 줄 · 출처 링크 글자(외부 링크 글자, 「출처:」 줄) · 표 머리 줄(th·thead, 마크다운 표 첫 줄) · 「」 안 법령명 · 「」 안 공식 명칭(문장이 아닌 40자 이하) · 기준일 꼬리말(「2026년 10월 3일 … 기준」 한 구).
- 정규화: NFKC → 소문자 → 글자·숫자·공백만 → 공백 하나. 21자는 공백을 포함한 글자 수다. 창 21자 롤링 해시로 찾고, 맞은 곳은 글자를 직접 비교해 확인한 뒤 이어진 곳을 한 덩어리로 묶는다.
- 출력 조각은 앞 20자까지만 찍는다(남의 글 20자 초과를 기록에 남기지 않음, H-133). `--show-text` 는 화면 확인용이고 커밋할 기록에는 쓰지 않는다.
- 같은 글 빼기: 상대가 대상과 같은 파일이거나 같은 폴더(작업/<날짜>_<영문>/ 의 원고·발행)면 뺀다.
- 쓰는 법(v2 2-7): 원천·구글 상위 3(임시 파일)과의 겹침 = 치명(종료 1). 우리 글(대기·라이브)과의 겹침 = 시범 기간 경고(`--warn`), 2주차부터 치명.
