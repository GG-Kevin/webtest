## 2. 새 CLAUDE.md에 들어갈 것(뼈대)
- **회사**: 서치는 티스토리 moneyproducer.co.kr에 한국어 금융 정보 글을 쓴다. 구글 검색과 애드센스가 수익원이다. 발행은 회장이 붙여넣는다(티스토리 API 없음).
- **자리 셋**
  - 사장(이 세션, Sonnet): 주제·검색어·고유 재료를 정하고, 계산 스크립트와 게이트를 돌리고, 집필·검수를 직접 부르고, 고칠 것을 직접 확인하고, 보고한다.
  - 집필 `seosa`(opus): 1회 + 수정 1회.
  - 검수 `geomsu`(sonnet): 치명 목록만 1회.
  - 이 밖의 자리는 없다.
- **공정**: 주제·검색어 → 고유 재료 계산(`작업/<주제>/calc.py`, 기준일·출처를 출력) → 집필 → `gate_search.py` → 검수 → 수정 1회 → 사장 확인 → `발행/정리/<번호>.html`·썸네일 1장(코드) → 보고 한 장(제목·고유 재료·검수 결과·**실제 비용**·붙여넣을 파일) → 커밋·푸시.
- **편당 $3 상한(추정)**: 넘을 것 같으면 수정 없이 검수로 넘긴다.
- **검수 치명 목록**: H-158 3절 전부 + H-159 두 줄.
  - 매수·매도 권유·수익 보장 금지
