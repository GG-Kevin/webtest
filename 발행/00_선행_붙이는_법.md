# 선행 1건 — 면책 페이지와 푸터 링크 붙이는 법

**본문 21편을 고치기 전에 이것부터 하십시오.** 본문에서 면책 문장을 빼는데 사이트 어디에도 면책이 없으면 안 됩니다.
**다섯 단계, 한 번에 끝납니다.**

---

## ① 면책 페이지를 만듭니다

1. 티스토리 **관리 → 콘텐츠 → 페이지 관리 → 새 페이지**
2. 제목에 **`안내와 면책`** 을 입력합니다 ← **글자 그대로. 띄어쓰기 한 칸.**
3. 에디터 오른쪽 위 **기본모드 → HTML** 로 전환 ← **여기가 중요합니다**
4. `발행/면책_페이지.txt` 를 열어 **전체 선택 → 복사 → 붙여넣기**
5. **발행**

> ⚠ **기본모드에 붙이면 안 됩니다.** 태그가 글자로 찍힙니다. 반드시 **HTML 모드**입니다.
> 📅 맨 끝 줄이 **`이 페이지 최종 수정일: 2026년 9월 23일`** 입니다. **오늘 날짜가 다르면 그 줄만 고치십시오.**

## ② 주소를 확인합니다 — **건너뛰지 마십시오**

발행 직후 그 페이지를 열어 **주소창의 주소를 봅니다.**

- **`https://moneyproducer.co.kr/pages/안내와-면책` 이면 그대로 ③으로 갑니다.**
- **다르면** (제목에서 만들어지는 주소라 달라질 수 있습니다) **그 주소를 복사해 두십시오.** ③에서 씁니다.

## ③ 푸터에 링크를 겁니다

1. **관리 → 꾸미기 → 스킨 편집 → html 편집**
2. **`skin.html`** 탭에서 **Ctrl+F** 로 아래 문자열을 찾습니다.

```
<div class="order-menu">
```

3. **그 줄 바로 다음 줄에** 아래 한 줄을 넣습니다. (`발행/면책_푸터링크.html` 와 같은 내용입니다)

```html
<a href="/pages/안내와-면책">안내와 면책</a>
```

> ②에서 주소가 달랐다면 `href="…"` 안의 주소를 **②에서 복사한 것으로 바꿔 넣으십시오.**

4. **적용**

> ✅ **`<a href="#" class="page-top">TOP</a>` 줄은 그대로 둡니다. 지우지 마십시오.**
> ✅ 색·크기·줄바꿈을 따로 넣을 것이 없습니다. **스킨이 `.order-menu a` 를 이미 꾸미고 있습니다** (PC는 한 줄, 모바일은 세로).

## ④ 눈으로 확인합니다 — 30초

| 볼 곳 | 맞으면 |
|---|---|
| 아무 글이나 열고 **맨 아래** | 「안내와 면책」 글자가 보인다 |
| 그 글자를 **누른다** | 면책 페이지가 뜬다 (404가 아니다) |
| 상단 메뉴 | 「안내와 면책」이 **자동으로 하나 더 늘어나 있다** |

**④가 통과해야 ⑤로 갑니다.**

## ⑤ 그 다음에야 본문입니다

`발행/정리/00_붙이는_법.md` 순서로 본문 21편을 갈아 끼웁니다.
**①~④ 없이 본문에서 면책 문장을 빼면 안 됩니다.**

## 이 페이지에 무엇이 들어 있나

본문 21편에서 걷어내는 문장 넷 중 **셋**이 여기 들어가 있습니다.

| 본문에서 뺄 문장 | 이 페이지 어디에 |
|---|---|
| `…의사결정의 책임은 이용자 본인에게 있습니다.` | **「책임」** 절 |
| `본 글은 2026년 N월 기준 일반적인 정보 제공을 목적으로…` | **「무엇을 위한 글인가」 + 「언제 기준인가」** 두 절 |
| `특정 종목의 매수·매도를 권유하거나 투자 자문을 제공하지 않습니다.` | **「무엇을 위한 글인가」** 절 (글자 그대로) |
| `이 글은 동전주 상장폐지 기준 총정리의 하위 글입니다.` | **여기 없습니다.** 면책이 아니라 글끼리의 연결이라, 각 글 본문 안의 문맥 링크로 바꿉니다 |

**「N월」이 사라진 이유** — 라이브 21편의 기준 월이 8월과 9월 두 값이고, 일자까지 적힌 편도 넷입니다.
한 달을 못 박으면 다른 편이 틀린 말이 됩니다. 그래서 이 페이지는 **「기준 시점은 글마다 다르니 각 글의 최종 수정일을 보라」**고만 씁니다.

> **이 페이지의 문장을 본문 21편에 다시 퍼 나르지 마십시오.** 같은 문단이 21편에 도로 깔리면 처음 문제로 되돌아갑니다. **면책은 이 한 장에만 둡니다.**
