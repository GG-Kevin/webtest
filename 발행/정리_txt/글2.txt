<h3 style="margin: 32px 0 12px; font-size: 1.2em; color: #2d3748;" data-ke-size="size23">25거래일 시점의 예고 공시</h3>

<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">보유 종목이 1,000원 근처라면 이 공시가 실질적인 첫 신호입니다. 2026년 8월 5일 기준으로 코스닥 51건, 코스피 17건의 예고가 발생했습니다.</p>

<h3 style="margin: 32px 0 12px; font-size: 1.2em; color: #2d3748;" data-ke-size="size23">가장 많이 혼동하는 두 지점</h3>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16"><b>첫째, 90일이 아니라 90거래일입니다.</b> 언론 보도 중에는 "90일 이내"로 쓴 경우가 있는데, 규정은 거래일 기준입니다. 거래일은 주말과 공휴일, 근로자의 날, 연말 최종일 등 휴장일을 제외하고 셉니다. 90거래일이면 달력으로 약 4~4.5개월입니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16"><b>둘째, 45거래일은 연속입니다.</b> 90거래일 동안 1,000원 넘긴 날을 합쳐서 45일이면 되는 것이 아닙니다. <b>끊기지 않고 45거래일</b>을 이어가야 합니다. 중간에 하루라도 1,000원 아래로 내려가면 처음부터 다시 셉니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">이 둘을 합치면 실질적인 여유는 생각보다 훨씬 적습니다. 90거래일 안에서 연속 45거래일을 확보하려면, <b>늦어도 45거래일째까지는 1,000원 위로 올라와서 그대로 버텨야</b> 합니다. 후반부에 반등해서는 물리적으로 요건을 채울 수 없습니다.</p>
<h3 style="margin: 32px 0 12px; font-size: 1.2em; color: #2d3748;" data-ke-size="size23">회복이 가능한 마지막 날은 46번째 거래일입니다</h3>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">90거래일 창 안에서 45거래일을 연속으로 채우려면, <b>늦어도 창의 46번째 거래일에는 종가가 1,000원 이상이어야 하고 그 상태가 90일째까지 한 번도 깨지지 않아야</b> 합니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">46일째에도 미달이면 남은 날이 44일뿐이라 산술적으로 45연속을 만들 수 없습니다. 창 후반의 반등은 요건 충족에 쓸모가 없다는 뜻입니다. 하루 급등을 &ldquo;요건을 채웠다&rdquo;고 볼 수 없는 이유가 여기 있습니다.</p>
<h3 style="margin: 32px 0 12px; font-size: 1.2em; color: #2d3748;" data-ke-size="size23">달력으로 언제쯤인지 계산하려면</h3>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">1년 매매거래일은 보통 240일 안팎입니다. 따라서 <b>90거래일은 약 18주, 4개월에서 4.5개월</b>입니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">여기서 흔한 오류가 나옵니다. 지정일에 <b>90을 그냥 더하면 달력상 3개월</b>이 되는데, 실제 만기는 그보다 한참 뒤입니다. 8월 중순에 지정된 종목이라면 90거래일 창은 11월이 아니라 <b>연말 무렵</b>에 닫힙니다. 추석, 개천절 대체휴일, 한글날, 성탄절, 연말 휴장이 모두 빠지기 때문입니다.</p>
<div style="margin: 0 0 22px; padding: 16px 18px; background: #f7fafc; border: 1px solid #e2e8f0; border-radius: 4px;">
<p style="margin: 0; line-height: 1.8; font-size: 0.95em; color: #4a5568;" data-ke-size="size16">휴장일은 매년 거래소가 확정합니다. 위 환산은 대략치이며, 개별 종목의 실제 만기는 <b>지정일 다음 매매거래일부터 실제 개장일만</b> 세어야 정확합니다.</p>

<h3 style="margin: 32px 0 12px; font-size: 1.2em; color: #2d3748;" data-ke-size="size23">회복 판정 방식 자체가 까다로워졌습니다</h3>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">이 &ldquo;연속 45거래일&rdquo;은 새로 도입된 방식입니다. 기존 시가총액 요건은 90거래일 동안 <b>&ldquo;연속 10거래일 및 누적 30거래일&rdquo;</b>만 기준을 넘기면 됐습니다. 짧게 여러 번 올라가는 것으로도 충족이 가능했다는 뜻입니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">개정 후에는 <b>한 번에 45거래일을 이어가야</b> 합니다. 금융위는 이 변경의 목적을 <b>&ldquo;일시적 주가띄우기를 통한 상장폐지 회피를 최소화&rdquo;</b>하기 위한 것이라고 밝혔습니다. 동전주 요건도 같은 방식을 그대로 적용받습니다.</p>

<h2 id="s4" style="margin: 44px 0 16px; padding-bottom: 10px; border-bottom: 2px solid #2d3748; font-size: 1.5em; scroll-margin-top: 70px;" data-ke-size="size26">4. 왜 지금 동전주가 급등하는가</h2>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">퇴출 제도가 강화됐는데 대상 종목이 오르는 것은 얼핏 모순처럼 보입니다. 구조를 보면 설명이 됩니다.</p>
<h3 style="margin: 32px 0 12px; font-size: 1.2em; color: #2d3748;" data-ke-size="size23">시한이 걸린 강제 부양 압력</h3>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">관리종목으로 지정된 기업 입장에서 남은 선택지는 사실상 하나입니다. <b>주가를 1,000원 위로 올려 45거래일을 버티는 것.</b> 실패하면 상장 자체를 잃습니다. 상장 지위는 자금 조달 능력과 직결되므로, 기업으로서는 물러설 곳이 없습니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">여기에 시장 참여자의 계산이 겹칩니다. 요건을 채우면 관리종목에서 해제되고, 그 과정에서 주가는 1,000원 위로 올라가 있어야 합니다. <b>퇴출 위기가 곧 상승 시나리오가 되는 구조</b>입니다.</p>
<h3 style="margin: 32px 0 12px; font-size: 1.2em; color: #2d3748;" data-ke-size="size23">우회로가 좁아졌다는 점이 결정적</h3>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">과거였다면 답은 간단했습니다. <b>주식병합</b>입니다. 10주를 1주로 합치면 500원짜리 주식은 산술적으로 5,000원이 됩니다. 기업 가치는 그대로인데 주가 표시만 올라갑니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">시장은 실제로 그 방향으로 움직였습니다. 2026년 1월 말부터 5월 중순까지 주식병합 결정 공시가 <b>176건</b> 나왔습니다. 전년 같은 기간은 6건이었습니다. <b>약 30배</b>입니다.</p>
<p style="line-height: 1.85; margin: 0 0 18px;" data-ke-size="size16">이번 개정은 이 경로에 제동을 걸었습니다. 다음 절에서 자세히 보겠지만, 요점은 <b>병합으로 숫자만 올리는 방식이 더 이상 자유롭지 않다</b>는 것입니다. 우회로가 좁아지면 남는 것은 실제 주가를 올리는 길뿐이고, 그 압력이 지금 일부 동전주의 급등으로 나타나고 있습니다.</p>
<h3 style="margin: 32px 0 12px; font-size: 1.2em; color: #2d3748;" data-ke-size="size23">압력이 만들어지는 경로</h3>
<ul style="line-height: 1.9; margin: 0 0 18px; padding-left: 20px;" data-ke-list-type="disc">
<li><b>지속 시간.</b> 연속 45거래일은 약 아홉 주입니다. 하루 상한가로는 요건이 채워지지 않고, 수 주간 종가를 유지해야 합니다.</li>
<li><b>리셋 공포.</b> 종가가 한 번만 999원으로 내려앉아도 연속 카운트는 0이 됩니다. 그동안에도 90거래일 시계는 멈추지 않습니다.</li>
<li><b>공개된 만기.</b> 지정일은 공시됩니다. 창이 언제 닫히는지 누구나 셀 수 있습니다.</li>
<li><b>얇아진 유통.</b> 지정 전에 병합을 마친 종목은 주식 수가 이미 줄어 있습니다. 같은 금액의 매수가 호가를 더 밀어 올립니다.</li>
<li><b>신용 수요 증발.</b> 관리종목은 신용거래가 금지되고 대용증권에서 빠집니다. 한쪽 수급이 줄어 남은 매수 주체의 영향이 커 보입니다.</li>
