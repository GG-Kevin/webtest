# 본문 정리본 — 붙이는 법

## 이 폴더에 있는 것

`발행/정리_txt/` — **`글2.txt` ~ `글25.txt`. 파일 이름의 숫자가 글 번호입니다.**
`moneyproducer.co.kr/5` 에 붙일 것은 `글5.txt`입니다. (`26`은 현재 404라 제외했습니다.)

> **확장자가 `.txt`인 이유:** `.html`로 두면 열었을 때 브라우저가 화면으로 그려버려서 원본 태그가 안 보입니다.
> `.txt`로 열어야 `<p style=...>` 같은 코드가 **글자 그대로** 보이고, 그걸 복사해야 합니다.
> (`발행/정리/*.html`은 같은 내용의 원본입니다. 작업에는 `정리_txt` 쪽을 쓰십시오.)

## 붙이는 순서

1. `글N.txt`를 열어 **전체 선택 → 복사**
2. 티스토리 글 관리 → 해당 글 → **수정**
3. 에디터 오른쪽 위 **기본모드 → HTML** 로 전환 ← **여기가 중요합니다**
4. **전체 선택 후 삭제**
5. **붙여넣기**
6. 저장

> ⚠ **기본모드(글쓰기 화면)에 붙이면 안 됩니다.** 태그가 글자로 그대로 찍힙니다. 반드시 **HTML 모드**에서 붙이십시오.
> 붙인 뒤 기본모드로 돌아가 한 번 훑어보면 제대로 들어갔는지 바로 보입니다.

> 이 HTML은 **티스토리 에디터가 만든 것을 그대로 가져온 것**입니다(`data-ke-size` 같은 티스토리 전용 속성이 그대로 있습니다). 그래서 되돌려 붙여도 깨지지 않습니다.

> **제목·카테고리·썸네일은 건드리지 않습니다.** 본문만 갈아 끼웁니다.

안내 박스의 나머지(편마다 다른 주의사항)와 최종 수정일은 그대로 뒀습니다.

## 남긴 것과 그 이유

- **`/17`·`/21`·`/24`** 에는 「투자 자문을 제공하지 않습니다」가 남아 있습니다. 이 셋은 그 앞 문장이 편마다 다르게 쓰여 있어 **한 문장으로 붙어 있습니다.** 떼면 문장이 깨집니다. 3편뿐이라 반복이 아닙니다.
- 목차·FAQ·핵심요약 박스는 **이번에 손대지 않았습니다.** 편마다 필요를 다시 판단해야 하는 일이라 기계로 할 수 없습니다.

**면책 페이지를 먼저 만드십시오.** 본문에서 면책 문장을 뺐으니 사이트 어딘가에 한 번은 있어야 합니다.

관리 → 콘텐츠 → **페이지 관리** → 새 페이지 → 제목 **「안내와 면책」** → HTML 모드 → `발행/면책_페이지.html` 붙여넣기 → 발행
