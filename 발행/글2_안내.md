# `/2` 재작성 — 붙이는 법

## 파일
- **`발행/글2_재작성.txt`** — 본문 HTML. 열면 태그가 글자 그대로 보입니다.

## 제목 (같이 바꾸십시오)

```
동전주 45일은 상폐되는 날 수가 아니라 살아남는 날 수입니다
```

기존: `동전주 상장폐지, 1,000원 회복 기한은 46번째 거래일입니다`

## 순서

1. 티스토리 글 관리 → **`/2`** (동전주 상장폐지 글) → 수정
2. **제목을 위 문장으로 교체**
3. 에디터 오른쪽 위 **기본모드 → HTML** 전환 ← 여기가 중요합니다
4. 본문 **전체 선택 후 삭제**
5. `글2_재작성.txt` 내용을 **통째로 붙여넣기**
6. 저장

> ⚠ 기본모드에 붙이면 태그가 글자로 찍힙니다. 반드시 **HTML 모드**에서.
> 카테고리·썸네일은 건드리지 않습니다. **썸네일은 회장 지시 대기 중입니다.**
