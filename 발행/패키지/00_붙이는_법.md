# 붙이는 법 — 새 글 (티스토리 HTML 모드)

편마다 폴더 하나입니다: `발행/패키지/<날짜_이름>/`

| 파일 | 용도 |
|---|---|
| `붙여넣기_HTML.txt` | **티스토리 HTML 모드에 붙이는 소스.** 열어서 전체 선택 → 복사 |
| `그림/01_대표.*` `그림/02_*.*` | 본문 그림 2장. **먼저 티스토리에 올려야** 합니다 |
| `썸네일.png` | 1080×1080. 글 설정의 대표 이미지(썸네일)로 올립니다 |
| `미리보기.html` | 붙이기 전에 눈으로 보는 용도(브라우저로 열기) |
| `본문_글자만.txt` | 글자만 뽑은 읽기용. 붙이는 용도가 아닙니다 |
| `붙여넣기_HTML_그림포함.txt` | **시험용.** 그림을 파일 안에 넣은 판입니다. 티스토리가 받아 주는지 아직 확인하지 않았습니다 |

## 순서
1. 티스토리 새 글 쓰기 → **기본모드**에서 `그림/` 안의 그림 2장을 올립니다(끌어다 놓기).
2. **HTML 모드**로 바꿔 올라간 그림의 `<img src="https://blog.kakaocdn.net/...">` 주소 두 개를 복사해 메모해 둡니다.
3. HTML 모드에서 **전체 삭제** 후 `붙여넣기_HTML.txt`를 붙여넣습니다.
4. 붙인 소스 안의 `src="그림/01_대표.png"` 같은 자리(파일 이름이 그대로 적혀 있습니다)를 2번에서 메모한 주소로 바꿉니다.
5. 기본모드로 돌아가 훑어보고, 제목·썸네일(`썸네일.png`)을 넣고 발행합니다.

> ⚠ 기본모드에 소스를 붙이면 태그가 글자로 찍힙니다. 반드시 HTML 모드입니다.
> ⚠ 첫 줄의 `<!-- 제목: … -->`, `<!-- 디스커버 제목: … -->`은 화면에 안 나오는 주석입니다. 글 제목 칸에는 그 제목을 직접 넣습니다.
> ⚠ **연봉 실수령액 편**은 계산기 스크립트(`<script>`)가 들어 있어 티스토리가 스크립트를 걷어낼 수 있습니다. 걷어내도 표로 답이 보이도록 만들었습니다. 라이브에서 계산기가 도는지는 발행 뒤 확인이 필요합니다.
