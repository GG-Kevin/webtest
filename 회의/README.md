# 회의

**회장과 사장이 나눈 말을 여과 없이 남기는 곳이다.**

---

## 왜 두나

사장도 서브에이전트처럼 매번 새로 불려 나온다. 다음 세션의 사장은 오늘을 모른다.
파일에 적힌 것만 남는데, **공정일지는 「무엇을 했나」를 남기고 결정 로그는 「무엇을 정했나」를 남긴다.
「어쩌다 그렇게 정했나」는 어디에도 안 남는다.**

회장이 무엇을 물렸는지, 어떤 말로 지적했는지, 사장이 무엇을 잘못 알아들었는지 —
**그 결이 여기 있다. 요약하면 그게 날아간다.**

## 규칙

- **요약하지 않는다. 교정하지 않는다. 지우지 않는다.** 오타와 말투 그대로 둔다
- **이 폴더의 파일을 나중에 다듬지 않는다.** 틀린 말도 그대로 둔다 — 그때 그렇게 말한 것이 기록이다
- **여기 적힌 문장은 규칙이 아니다.** 규칙은 `운영/03_운영규칙.md`, 결정은 `운영/07_결정로그.md`에만 있다

## 어떻게 뽑나

```
python3 회의/추출.py [세션ID]
```

원본은 `/root/.claude/projects/-home-user-webtest/<세션ID>.jsonl`이다.
**그게 진짜 원본이고, 이 폴더는 거기서 회의 부분만 뽑아낸 것이다.**

**남기는 것** — 회장의 말, 사장의 답. 사장이 답변에 옮긴 에이전트 발언은 사장 답의 일부이므로 그대로 남는다.
**빼는 것** — 도구 호출, 파일 내용, 시스템 알림, 서브에이전트 내부 대화. 회의가 아니다.

## 한계 — 알고 쓸 것

- **세션이 끝나야 온전하다.** 진행 중에 뽑으면 그 시점까지만 나온다
- **원본 JSONL은 이 저장소 밖에 있다.** 컨테이너가 사라지면 원본도 사라진다. **뽑아서 커밋해야 남는다**
- **자동으로 안 된다.** 사장이 뽑아서 커밋해야 한다
